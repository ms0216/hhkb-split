`tools/export_fab.py` は共有されている補正表（matthewlai/JLCKicadTools）を
当てているが、**それが JLCPCB にとって正しいかは、こちらからは検証できない。**

JLCPCB の発注ページに部品を並べた**配置プレビュー**が出る。そこで見る。

| 見るもの | 何が起きうるか |

| **74LVC595（U1・右は U2 も）** | 補正 270 度を当てている。**ずれていたら 90 度単位で回っている** |
| **ダイオード 61 個（D1〜）・D_PWR** | **向きが逆だと 1 つも反応しない。**カソード（帯）が行の側。**2026-08-16 判明・未対応**: `ROTATION_DB`（出典 matthewlai/JLCKicadTools）に SOD 系の補正値が 1 件も無く、無補正のまま出している。同ツールの Issue #28 で「同じ SOD パッケージでも LCSC 品番により向きが違う」既知の限界が報告済み。JLCPCB の配置プレビューで D_PWR（B5819W・C7420330）を目視すると「+」マークが出るが、**これが Pin 1 を指すのか、KiCad 側のカソード位置と何度ズレているのかは未確定**（JLCPCB の UI にツールチップ等の裏付けが無い）。**この基板は `export_fab.py` を使わず、別の KiCad プラグインで CPL を作る運用**なので、このリポジトリの `ROTATION_DB` を直しても実際の発注には効かない。**発注前に必ず配置プレビューで目視し、カソード（帯）が V3V3 側に来ているか確認すること**（[open-gaps #52](open-gaps.md)。旧 #42・GND スタブの #42 と衝突していたので 2026-08-24 に改番） |
