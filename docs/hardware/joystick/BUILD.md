受け皿のつば（1.5mm）は裏返すと支えの無い張り出しになる。だれるようなら支えを付ける。
1. 受け皿 2 つ・キャップ（造形だけで合計 約 22 分。別々に刷ると準備込みで 約 45 分）: `print/left_tray.stl`・`right_tray.stl`・`right_stick_cap.stl`

4. キャップは軸にきつめに入ること。**軸は φ4 で、先端 5mm だけ向かい合う 2 面が幅 3mm に落としてある（二面取り）。**穴は φ4.1 × 幅 3.1。

### 2-3. スティックに線を付けて、受け皿に組む（プレートは要らない）

2. 線を受け皿の長穴に通し、スティックを床に座らせる
3. 爪 4 本を、マイナスドライバーの先で内側へ押し倒す（床の下に出るのは 1.1mm）
4. 線を、受け皿の輪の下（脚の間・高さ 2.4mm）から平らに並べて、キーの側へ出す

### 2-4. 線を帯と XIAO につなぐ
1. スティックの 9 本を帯の穴へ（`pod_layout_parts_side.png` の緑の印。上端 2 本・下端 2 本・スイッチの片側・枠は、同じ色帯の別の穴）
2. 右の XIAO をソケットから抜く（筐体は「始める前に」の状態）。**部品の付いた面を上・USB を奥**にして見たとき:
   - 左の列（奥から）: D0・**D1**・D2・D3・**D4**・D5・D6
   - 右の列（奥から）: 5V・**GND**・**3V3**・D10・**D9**・D8・D7
3. 帯からの 4 本（各 8cm）を、XIAO の**ピンの頭（上面に出ているはんだの山）**に付ける: 3V3・GND・D4（SCL）・D9（SDA）
4. ⚠️ 左右の列の向きは、XIAO の裏のシルク（D0〜D10）で必ず確かめる。基板の設計データ（フットプリント）とは一致を確かめたが、Seeed の公式の図とは突き合わせていない

### 2-5. 机の上で動かす
1. XIAO をソケットへ戻す（線は上へ逃がす）。右の XIAO を USB でつなぐ

     `stick-pod-trial` のファームでは直してある（ビルドのみ・実機未確認）。**もし 2 分ほどで止まったら**、電池を入れて電源スイッチ ON のままつなぎ、知らせてください
2. 右に `hhkb_split_right-pod`、左に `hhkb_split_left-podR-encB` を焼く
   （GitHub の Actions → `Build ZMK firmware` → ブランチ `stick-pod-trial` の成果物。焼き方はリポジトリ直下の `docs/hardware/xiao-flash-recovery.md`）

3. 見る所: 倒すとポインタが動く（向きが逆・X と Y の入れ替わりは設定で直せる）／押し込みで中ボタン／

### 2-5b. ログの見方（動かなかったとき）
1. ログの出る版を焼く: 右 `hhkb_split_right-pod-log`、左 `hhkb_split_left-podR-encB-log`（電池で常用しない）
2. 見たい側だけを USB でつなぎ、Mac で `ls /dev/cu.usbmodem*` → 出た名前で `screen -U /dev/cu.usbmodemXXXX 115200`
   （`-U` を付けないと日本語が化ける。終わるときは Ctrl-A → K → y）
3. **大事な行は起動直後に 1 回しか出ない。**ログ版は起動から 8 秒ログを溜めてから出すので、リセット（XIAO のボタンを 1 回、
   または sys 層の再起動キー: 左は Fn+Ctrl+5、右は Fn+Ctrl+7）→ 切れたらすぐ同じ `screen` を打ち直す、で拾える
4. 右で見える行（名前は `hhkb_stick_pod`）と、その読み方。**左も動かしておく**（左が居ないと右は 2 秒に 1 回しか読まず、中心の採用に 16 秒以上かかる）:

   | 見えた物 | 意味 | 次にやること |
   |---|---|---|
   | `ポッドを見つけた: 版 1・ブート ID …`（起動ごとに 1 回） | I2C が通り、正しいフレームが届いた | — |
   | `保存してあった中心: …` | 前に採用した中心を使っている（2 回め以降の起動はこちら） | 中心がおかしいときは、取り直しのキー（sys 層の C の位置）を、手を離して押す |
   | `中心を採用した: …`（初回と取り直しのとき。手を離して数秒） | ここからポインタが動く | — |
   | `中心を 1 分採用できていない（倒したまま？ X/T=… Y/T=…）` | 中点が真ん中に無い**か、読みが揺れてそろわない** | X/T・Y/T を知らせてください。32768 から遠い → X と Y の線の取り違え・上端と下端の逆。32768 前後なのに出る → 読みの揺れ（設定 `centre-stable-lsb` を広げた版を渡します） |
   | 上のどれも出ず、数字の行で **NACK が増える** | マイコンが返事をしていない | 配線（SCL=D4・SDA=D9・3V3・GND）・書き込み・ヒューズ |
   | 同じく **タイムアウト が増える** | 線が Low に張り付いている | SCL・SDA の短絡、3V3 か GND の外れ |
   | 同じく **範囲 が増える**（NACK は 0） | 返事はあるが、上端の電圧が読めていない | 逃げ道: 上端 → 1kΩ → キットの A4 に線を足し、別の版を書く（知らせてください） |
   | 同じく **CRC・マジック が増える** | 線の雑音か接触 | 線を短く・はんだを見直す |
   | `ポッドを見失った（…）`／`不在: …`／`復帰: …` | 読めなくなった／戻った | 続くなら接触 |
   | `固着: …` | **倒れたまま 5 分動かない**か、5 分押しっぱなし。止めるのが正しい動き | 物が載っていないか見る |

   数字の行（`受理 … / NACK … / タイムアウト … / CRC …` と `範囲 … / 使い回し …`）は、見失ったとき・戻ったとき・10 分おきにしか出ない
5. 左で見える行（ログ版は B 案だけ）: エンコーダを回すと ZMK の `val1: 15 … triggers: 1`（または −15・−1）が 1 刻みに 1 行出る。刻みの数と向きはこれで分かる

4. ファームは同じ

### 2-7. 筐体に入れる（⚠️ この節は、この筐体を実際に開けて確かめた手順ではない）

3. 受け皿（スティックと線が付いている）を、新しいプレートのくり抜きに下から当てる

## 3. 左手（エンコーダ）

### 3-2. エンコーダに線を付けて、受け皿に組む
1. 足 1 本につき線 1 本: 3 本の側の全部（両端が A と B・真ん中が C）、4 本の側の**両端**（押し込み。端子 1 と 4）= **5 本**。4 本の側の内側 2 本（LED）は使わない
   - 0 章 4 で「いつも開いている」と分かった相を **a**、もう片方を **b** と呼ぶことにして、線の色を書き留める
   - 押し込みの 2 本は、どちらを「端子 1」「端子 4」と呼んでもよい（スイッチに向きは無い）
   - A・C・B・端子 1 は各 8cm（帯まで約 3cm）。**端子 4 の線は 12cm**（主基板の裏の「5」のキーのソケットへ行く）
2. 線を受け皿の長穴に通し、エンコーダを座らせ、爪 2 本を**内側へ**押し倒す（外側は縁に当たる）

### 3-3. つないで、机の上で動かす
1. a・b・C・端子 1 を帯へ（配置図の緑の印。**a を「A」の穴、b を「B」の穴**へ）
2. 左の XIAO を抜き、帯からの 5 本（各 8cm）をピンの頭へ: 3V3・GND・D4（A 相）・D9（B 相）・D5（行 4）。列の並びは 2-4 と同じ
3. 端子 4 の線を、主基板の裏の**「5」のキーのソケットの「列の側」のパッド**へ（T のソケットと導通する方）
4. 左に `hhkb_split_left-podR`（A 案）を焼く
5. 見る所: 回すとホイール（1 刻みで 1 段）。向きは、どちらに回すと下へスクロールするかを見て、**好みと逆なら** a と b の線を入れ替える（帯の「A」「B」の穴を逆に）か、知らせてください
   （規格書の図の「時計回り」だと下スクロールになる計算。A と B のどちらの足がどちらかは現物しだい）／Fn＋回すと拡大縮小／押すと左クリック／Fn＋押すと右クリック
6. **USB を抜き、電池で**、止めたまま 35 分置いて、スリープに入るか（設定は 30 分。**USB をつないでいる間は、ZMK は寝ない**。
   入ったかどうかは、キーを押しても数秒つながらないことで分かる）

A 案（ZMK 標準の読み方）について、ソースを読んで分かったこと:
- どちらの相が動いても ZMK に「操作あり」と伝わる。B 相が境目でばたつくと寝ない
- 電源の管理が無いので、**寝ている間も** 100kΩ に電流が流れる（B 相が閉じて止まっていれば約 29µA）

### 3-4. B 案（待機電流ゼロ）を試す — **机の上で動けば、こちらを本命にするのがよい**
1. `hhkb_split_left-podR-encB` を焼く（3-3 の 1 で a を「A」の穴＝D4 へつないであれば、設定はそのままでよい）
2. **b の側（帯の「B」＝D9）の抵抗 100kΩ は外す**（片足を浮かせるだけでよい）。残すと約 29µA が流れ続ける。a の側は付いたままでよい
3. 回す向きは A 案と同じになる（同じ配線なら入れ替えても変わらない。机上の検査で確かめた）。逆にしたいときは設定 1 行（`invert`）で直すので、知らせてください

### 3-5. 筐体に入れる（⚠️ 2-7 と同じく、実物で確かめた手順ではない）
1. プレート＋スイッチ＋主基板のかたまりを抜き、スイッチを新しいプレートへ移す（右と同じ）
2. 受け皿をくり抜きに下から当て、主基板を戻す
3. a・b・C・端子 1 の線は、主基板の奥の縁の外、**XIAO のソケットの左の脇（幅 1.8mm の隙間）**で下へ降ろして帯へ（`images/left_r_route.jpg` の赤い線）。
   **縦 1 列に並べる。**帯 → XIAO の 5 本と、端子 4 →「5」のキーの 1 本も同じ隙間を通る（合わせて 10 本）
4. 帯を両面テープで底板に貼る（主基板の下。場所は `images/left_r_inside.jpg`）
5. かたまりを戻し、底板を閉じる
6. **つまみは最後。一度挿すと外れない**
