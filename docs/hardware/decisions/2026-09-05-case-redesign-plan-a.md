## 留め（HELD_BY の新版）

上シェル = 手前 M2×3 ＋ スカート（位置決め）＋ 奥板リップ。奥板 = M2×2。
電池箱 = M2×2。電源 SW = 溝＋奥リブ＋**上シェル奥縁の裏面が上への抜けを塞ぐ**。
プレート = 下シェルの手前壁と側壁の帯（リム面）が受け、上シェルのベゼルの縁が
押さえる（4 辺。光線走査で確認: 左右 25/25・奥 34/34・手前 31/34、無い 3 点は
ネジ穴）＋手前共締め。奥端は上シェルの棚（溝に傾けて差し込む・`PLATE_REAR_GAP` 0.5）。

## 頑丈さ・ズレ止め（2026-09-05・利用者「見えない所ならネジを増やしてよい」）

- **手前 M2×3 のボス**: 円柱 φ5.6・中心 51.5 ではインサート（外径 3.2）の外側の
  肉が 0.46 で、圧入で割れる。基板の手前縁（平面図 48.31）が動かせないので、
  ボスを**壁と一体の角柱**にして内端を基板の縁 + 0.2 で止め、インサートを
  内へ寄せた（`MOUNT_Y` 50.91）。肉は内側 0.8 / 外側 1.05。ベゼルの座ぐりが
  外面を 0.14 破っていた問題も消えた。捕まえナット案は「工具を増やしたくない」
  で見送り（実際は工具不要だが、部品が増える）
- **奥面 3 本目の M2**: 奥板のリップは電池窓の幅（109）しか押さえない。子基板側
  （x = 子基板中心 − 8、z ≈ 27）で奥壁を貫き、上シェルの天井裏のボスへ
- **開口を 7.3° に傾けて切る**: 垂直に切っていた開口は、キャップの面と 7.3°
  ずれ、手前段では隙間 0.9 の時点で縁まで 0.18 しか無かった（0.725 で接触・
  箱モードが 0.03mm³ で検出）。プレートと同じ姿勢で切り、全段で隙間 0.725
  （見え 1.05）。最下段の覆いも同じ姿勢。`plate_placement` を gen_case へ移した

## 奥の棚の剛性（計算・2026-09-05）

利用者の懸念「上辺の受けは撓み防止のためだったはず」への答え。荷重はキーを
底まで押し切る 1〜2 N（キー 60 gf ＋ 底打ち）。
- 棚を吊るベゼル奥のバー（5.65 × 6.6、長さ 140）だけで I ≈ 135 mm⁴、中央 2 N で
  δ = FL³/(48EI) ≈ 0.24 mm（E = 3.5 GPa 文献値。FDM は 2 GPa 程度で最悪 2 倍）。
  実際は天井板・スカート・桟・奥板が繋がるのでこれより小さい
- 旧（天井から垂らしたフランジ 2.4 × 11）: 同じ式で ≈ 0.12 mm。同じ桁
- 受け無し（2026-08-29 の状態、プレート 1.5 の片持ち 100 mm）: ≈ 4.9 mm
→ 受けとしては足りる。試し刷りで指で押して確かめる。

## 新しい検査

- 奥板を外すと上シェルが上へ抜ける／付けると 0.3mm で当たる
- 電池箱のネジ軸線上に奥の窓からドライバー φ6 が通る
- スカートと外壁の重なり ≥ 3mm・外形幅が 144.4 / 177.7 を超えない
- 上シェルの見せ面（ベゼル面）が一平面（印刷向きの前提）
