## 新しい事実（データシート BH-325-1A・図面 3251A-0410）

- 109.0±1.0 × 16.6±0.5 × 16.8±0.5。**電池は上面（長辺の開口）から入れる樋型**
  → 奥から出し入れするには箱を横倒しにして開口を奥へ向ける
- **床に φ2.4 の取付穴 2 個**（内側から φ3.8×0.8 の座ぐり）→ M2 で締められる。
  「囲うだけ」（旧 HELD_BY）は部品側に固定手段があるのに使っていなかった
- ソケット板下 1.80（PG151101S11）、MX のプレート〜基板 3.5 は Cherry 規格そのもの。
  箱は基板の下に潜らないので、コブ深さに効くのは奥の余白と壁だけ

## 構成

| 部品 | 役割 | 印刷の向き |
|---|---|---|
| 下シェル `case` | 床・側壁・奥壁（SW 溝・USB-C・LED 窓）・電池室・子基板ボス・底面造作 | 床を下 |
| 上シェル `topcase` | ベゼル面＋コブ天井（**一枚の 7.3° 面**）＋スカート（手前・左右） | **ベゼル面を下**（平面なので段差ゼロ） |
| 奥板 `rear_plate` | 電池窓（109 幅）を塞ぐ板＋全幅の上縁リップ（上シェル奥縁を押さえる） | 外面を下 |
| プレート・脚・ゴム足・ナット | 現行どおり | |

- 側面の合わせ目: **水平・手前のリム面の高さ**（`SEAM_Z = PLATE_TOP_FRONT − PLATE_T`
  ≈ 9.49。実機写真「中ほど」の目測 9 と同じ帯）。合わせ目より上の側壁は
  **上シェルの物**（壁 2.4 のまま。二重壁にしない）。相欠き 3mm だけ
  下シェル 1.0 ／ 上シェル 1.2 に分ける。**手前壁は相欠きにしない**——手前の
  ネジボスが外面に接していて、外側を削ると熱圧入インサートが露出する
  （箱モードの検査が 0.19mm³ で捕まえた）。手前はリム面で突き合わせ。
  **外形幅は不変**
- 実機再現（dimensions.md §4）: 上下シェルの合わせ目（3）、手前面の傾き 12°・
  上縁 R6（1・2、目測）、底縁 R1.5（4 の代用）。手前端 17.5 は不変
- 奥: スカート無し。上シェルの奥縁は奥壁の上に突き合わせ、奥板のリップが押さえる
- 電池箱: 横倒し（開口が奥）、仕切り壁へ M2×2。コブ深さ **17**（CAD で確定）
- 奥板: M2×2 を奥壁のボスへ水平に。ビード・庇・舌・スライドは全廃
- 隙間: スカート 0.2 / 奥板 0.3［未実測・クーポン先行］

## 留め（HELD_BY の新版）

上シェル = 手前 M2×3 ＋ スカート（位置決め）＋ 奥板リップ。奥板 = M2×2。
電池箱 = M2×2。電源 SW = 溝＋奥リブ＋**上シェル奥縁の裏面が上への抜けを塞ぐ**。
プレート = ベゼル壁とリムで挟む＋手前共締め＋奥は上シェルごと奥板で押さえる。

## 組み立て順（INSERT_PATH）

① 電池箱を奥の窓から ② 子基板を手前から入れて上へ ③ プレート＋基板を真上から
④ 上シェルを真上から、手前 M2×3 ⑤ 奥板 M2×2。斜め差し・撓ませる操作は無し。

## 新しい検査

- 奥板を外すと上シェルが上へ抜ける／付けると 0.3mm で当たる
- 電池箱のネジ軸線上に奥の窓からドライバー φ6 が通る
- スカートと外壁の重なり ≥ 3mm・外形幅が 144.4 / 177.7 を超えない
- 上シェルの見せ面（ベゼル面）が一平面（印刷向きの前提）
