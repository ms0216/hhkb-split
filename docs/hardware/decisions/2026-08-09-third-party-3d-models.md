# 第三者の 3D モデル（ライブラリ）をどう選び、どう扱うか

2026-08-09。open-gaps #29 の途中で、Kailh ソケット・スタビライザの
3D モデルに kiswitch（旧 perigoso/keyswitch-kicad-library）を導入した。
その際に使った基準を、次回のために一般化して残す。

## 大原則

**第三者のモデルは「外部の事実」ではない。誰かの作図＝主張である。**
この案件の階層（データシート・API・実測 ＞ 生成物）は変わらない。
モデルは、データシートが読みにくい形状を先に数字にしてくれる**中継ぎ**
として使い、**採用条件は「データシートと矛盾しないこと」**。
矛盾の確認ができないモデルは、便利でも採らない。

## 選定の優先順位（上から順に当たる）

0. **まずメーカー公式を探す。**公式配布の CAD（STEP）があればそれが最上位。
   無ければ、公式の一次情報は**データシートの図面**になる（それが照合相手）。
   Kailh は公式 CAD を配布しておらず（2026-08-09 に確認。あるのは
   GrabCAD・SnapEDA などの第三者作図のみ）、データシート図面を使った。
   ⚠️ この確認を飛ばして第三者から始めない（一度飛ばして指摘された）
1. **照合できるか（必須条件）。**
   突き合わせる相手（データシート・現物）があるか。無いなら採らない。
   今回: Kailh 公式データシート（PG151101S11）と突き合わせ、
   板下厚 1.80 / ボス込み 3.05mm がモデルの実測と一致した
2. **設計が既に宣言している出所か。**
   フットプリントが `(model ...)` で宣言しているライブラリなら、
   宣言と実体が一致し、二重管理が生まれない。**別のライブラリを選ぶと
   「宣言は A・実体は B」というねじれを自分で作ることになる。**
   今回: フットプリントの宣言先（perigoso → 現 kiswitch）をそのまま使った
3. **形式が用途に合うか。**
   `.wrl`（視覚用）だけのライブラリは `kicad-cli` の STEP 出力に乗らない。
   `.stp`/`.step` が同梱されていること（kiswitch は両方ある。
   `--subst-models` で置換される）
4. **ライセンス。**
   リポジトリに**入れて再配布する**なら適合確認が要る。**利用者の環境に
   置くだけ**なら要件は軽い。kiswitch は MIT ＋ CC-BY-SA の二重で、
   今回はリポジトリ外（`~/Documents/KiCad/10.0/3rdparty/`）に置いた
5. **導入したら検査が増える形にできるか。**
   「入れて見た」で終わらせず、数と寸法を機械で数えて記録に落とす
   （`tools/pcb_parts.py` → JSON → pytest）。数えられない導入は、
   KiCad が黙ってモデルを飛ばす罠（#29）に対して無防備になる

## 導入後にやること（毎回）

- **数を数える。**STEP の立体数が宣言と合うか（`pcb_parts.py --write`）
- **データシートと突き合わせる。**支配的な寸法（今回なら板下に出る厚み）だけでよい
- **保守的な占有空間との関係を検査にする。**モデル ⊆ 箱 を機械で確認
  （箱が保守側でなくなったら落ちる）
- **確定は現物で。**モデルとデータシートが一致しても [暫定] は外さない。
  外すのはノギスで測ったとき

## 適用実績

| 部品 | 出所 | 置き場所 | 照合 |
|---|---|---|---|
| Kailh ソケット・スタビ | kiswitch（第三者。公式 CAD 無し） | リポジトリ外（宣言どおりの 3rdparty パス） | データシート PG151101S11 と一致 |
| **XIAO nRF52840** | **Seeed 公式**（wiki の Resources） | **リポジトリ内** `pcb/lib/hhkb_split.3dshapes/`（公式配布なので同梱。出所は同ディレクトリの README） | 実測 21×18×4.5 と一致（モデル 20.95×17.78×4.46） |

XIAO のモデルは導入時に新事実も出した（USB のメス面が外形端より
1.26mm 奥に突き出る。open-gaps #29 の発見 5）。**モデルは照合相手が
あって初めて価値を出す**という基準どおりの結果。

## 再インストール手順（このマシン以外・OS 再構築時）

```
git clone --depth 1 https://github.com/kiswitch/kiswitch.git /tmp/kiswitch
D=~/Documents/KiCad/10.0/3rdparty/3dmodels/com_github_perigoso_keyswitch-kicad-library/3d-library.3dshapes
mkdir -p "$D"
cp /tmp/kiswitch/library/3dmodels/3d-library.3dshapes/{SW_Hotswap_Kailh_MX,Stabilizer_Cherry_MX_2.00u,Stabilizer_Cherry_MX_3.00u}.{wrl,stp} "$D/"
```

モデルが無い環境で `pcb_parts.py --write` を叩くと立体数が減り、
`test_step_component_counts_match_the_circuit` が落ちて気づける。
