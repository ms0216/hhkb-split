# 2026-08-16 調査 FFC 越しのループインダクタンスの桁

**⚠️ これは机上の見積もりであって、実測ではない。**オシロもLCRメータも
当てていない。**「測った」と書いていない箇所は全部計算である。**
未実測値としての扱いは `provisional-values.md` と同じ。

**結論を先に**:

| | |
|---|---|
| XIAO の 3V3_OUT → 主基板の 595（C_U1）までの往復ループ | **150 nH の桁**（数十〜200nH） |
| うち FFC 本体の寄与 | **約 64 nH ＝ 全体の 4 割強** |
| **支配的なのは何か** | **FFC ではない。「FFC ＋ 両基板の 0.2mm 幅 V3V3 配線」の 3 つがほぼ同じ桁で並ぶ** |
| §3「ns 級は FFC を渡れない」 | **支持される**（ただし理由は「FFC が大きいから」ではない・§5） |

---

## 1. 効く条件と、支配的なのはどれか

依頼で挙がった 4 つを埋めた。**順位は依頼の予想と違った。**

| # | 条件 | 実データ | 寄与 |
|---|---|---|---|
| 1 | FFC 本体 80mm | `envelopes.py:392` `FFC_LENGTH = 80.0`・0.5mm ピッチ | **約 64 nH** |
| 2 | 往復の組み合わせ（GND 1 本） | **GND は 1 番の 1 本のみ**・V3V3 は 2 番＝**隣接 0.50mm**（実測ではなく座標から。§2） | 上の 64nH に織り込み済み。**隣接なのが効いていて、これ以上は悪くない** |
| 3 | **両端のコネクタからパッドまでの引き回し** | **子基板 28.3mm ＋ 主基板 68.4mm の 0.2mm 幅トレース**（§3） | **約 81 nH ＝ 最大の寄与** |
| 4 | FFC の物理的な取り回し（曲げ） | `FFC_SLACK = 25.0`（暫定値） | 往復が隣接ピンで閉じるので**ほぼ効かない**（§6） |

> ★**支配的なのは 3 番だった。**依頼は「たぶん 2 番」と予想していたが、
> 2 番（GND 1 本・隣接配置）は**すでに最善に近い**。実際に効いていたのは
> **両基板側の細い V3V3 トレース**で、合計 96.7mm ある。
> **「80mm × 何 nH/mm」で終わらせるなという注意は正しく、しかも
> 止まってはいけない場所が FFC の外側だった。**

## 2. GND の戻りの実データ（作法 6・接頭辞で走査していない）

`circuit.py` の `J_MAIN`/`J_DB` と、`pcb/*.kicad_pcb` の footprint ブロックを
**S 式で構文解析して**パッドごとにネット名を読んだ（目視でもグレップでもない）。

| | 結果 |
|---|---|
| GND の本数と位置 | **1 本・1 番ピン**（両端とも一致） |
| V3V3 の位置 | **2 番ピン ＝ GND の隣** |
| 物理的な離れ | **0.50mm**（パッド座標から: 主基板 212.63→212.13、子基板 152.75→152.25） |
| 両端で GND が落ちる先 | **両基板ともベタ**（`zone net=GND` が F.Cu と B.Cu の両方に存在）。**細い配線ではない**。GND のトレース長は子基板 4.8mm・主基板 4.3mm しかなく、すぐ面に落ちている |
| GND ビア | 子基板 54 本・主基板 1093 本 |

**戻り側は基板の上では問題になっていない。**問題は行き側（V3V3）だった。

## 3. 行き側 V3V3 は細く長い ← ここが今回の発見

同じ解析で、V3V3 ネットのトレースを全部足して、FFC パッドからの
経路長を BFS で測った。

| 基板 | V3V3 トレース総延長 | 幅 | FFC パッドからの経路 |
|---|---|---|---|
| 子基板 | 32.8mm（B.Cu） | **0.2mm** | J_MAIN → `U_MCU` の 3V3 パッドまで **28.3mm** |
| 主基板 | 72.2mm（B.Cu 43.9 ＋ F.Cu 28.3） | **0.2mm** | J_DB → `C_U1` まで **68.4mm**、`U1` pad16 まで **69.8mm** |

**GND はベタなのに、V3V3 は 0.2mm 幅で 97mm 引き回されている。**
これが往復ループの片道を作っている。

## 4. 桁の見積もりと、その出典

### 4-1. FFC 本体 — 外部の公表値 2 系統が一致した

**自分の仮定だけで組み立てていない**（作法 3）。独立な 2 通りで出した。

**(A) 公表された Z₀ と C から**（Würth Elektronik・TRILOGY OF CONNECTORS 3.3
「Measurement of the Characteristic Impedance of a Flat Flexible Cable」、
および 0.5mm ピッチ FFC の公表値 **C = 62 pF/m・Z₀ = 130 Ω**）:

```
L' = Z₀² · C
   Z₀=130Ω → L' = 1.05 nH/mm  → 80mm で 84 nH
   Z₀=100Ω → L' = 0.62 nH/mm  → 80mm で 50 nH
```

**(B) 平行 2 導体の解析式から**（`L = μ₀/π · [ln(d/r) + 1/4]`）。
寸法は **Würth WR-FFC 0.5mm ピッチのデータシート実寸**
（687626152002: 導体幅 **Cw = 0.3mm**・導体厚 **Ct = 0.05mm**・ピッチ 0.5mm・
絶縁 PET）。矩形導体の等価半径は (w+t)/4 = 0.0875mm:

```
L' = 0.80 nH/mm → 80mm で 64 nH
```

| 出どころ | 種別 | L' | 80mm |
|---|---|---|---|
| Würth Z₀=130Ω・62pF/m | **外部の公表値** | 1.05 nH/mm | 84 nH |
| 解析式＋データシート実寸 | **外部寸法＋教科書式** | 0.80 nH/mm | 64 nH |
| ribbon の一般値（G-S-G で Z₀ 80〜100Ω） | 外部（IEEE/UMBC 講義資料） | 0.6〜0.8 nH/mm | 50〜64 nH |

**3 つとも 0.6〜1.05 nH/mm に収まる。FFC 80mm は 50〜85 nH、
つまり「数十 nH」で確定。**桁として **64 nH** を代表値に採る。

⚠️ 「A タイプ／B タイプ」（同面／異面接点）は**この桁には効かない**。
効くのは導体の並びとピッチで、それは A/B で同じ。

### 4-2. 基板側トレース — 自分の計算（グランド面上のマイクロストリップ）

`L' = μ₀/2π · ln(8h/w + w/4h)`、w=0.2mm、h=1.6mm（2 層 FR4）→ **0.83 nH/mm**。
h=0.8mm でも 0.69 nH/mm で、桁は動かない。

| 区間 | 長さ | L |
|---|---|---|
| 子基板 J_MAIN → XIAO 3V3 | 28.3mm | **24 nH** |
| 主基板 J_DB → C_U1 | 68.4mm | **57 nH** |

### 4-3. 合計

```
XIAO 3V3_OUT →[子基板 24nH]→ FFC[64nH] →[主基板 57nH]→ C_U1 / 595
                                 合計 約 145 nH
```

**FFC の取り分は 44%。**残り 56% は両基板の細い V3V3 配線である。

**→ 答え: 数十 nH でも数百 nH でもなく、「150 nH の桁」。**

## 5. §3 の「ns 級は FFC を渡れない」は支持されるか

**支持される。ただし §3 が書いた理由づけは不正確だった。**

74LVC595 の遷移時間を 2〜3ns とすると、knee 周波数は **167〜250 MHz**。

| | 値 |
|---|---|
| 145nH の \|X_L\| @167MHz | **151 Ω** |
| 595 の直近 `C_U1`（0.1µF・0805）の局所枝 \|Z\| @167MHz（ESL 約 2.5nH 相当） | **2.6 Ω** |
| 分流比 | **約 58 : 1** |

595 のエッジ電流は **98% 以上が C_U1 で主基板上に閉じ**、FFC を遡るのは
2% 未満。**C_DB は 595 のエッジに対して事実上見えていない。§3 の結論は正しい。**

**ただし §3 の書き方は直したほうがよい:**

> §3 現行:「**ns 級のループは FFC を渡れない**」＝ FFC が大きいから

**FFC 単体（64nH）だから渡れないのではない。**基板側の配線（81nH）を
足した合計と、C_U1 の局所ループの小ささ（数 nH）の**比**で決まっている。
**FFC を 0mm にしても 81nH 残り、それでも分流比は 30:1 以上で結論は動かない。**
つまり **§3 の結論は FFC の存在に依存していない**——依存しているのは
「595 が自分の直近にパスコンを持っている」ことのほうである。

**これは削除の判断を弱めない。むしろ根拠として強い。**
「FFC のインダクタンスが十分大きいから」という論拠は
**必要ではなかった**（C_U1 があれば足りる）。

⚠️ **C_DB と 145nH が作る共振**も見た。f₀ = 1/(2π√(LC)) ≈ **1.3 MHz**。
595 のエッジ（167MHz 級）からは 2 桁下で、**ここが励振される筋は無い**。
LDO のループ帯域（数十〜数百 kHz・§4）よりは上なので、
**C_DB はどちらの帯域も担当していない**という §4 の結論とも整合する。

## 6. 曲げ・取り回し（条件 4）が効かない理由

往復が **隣接ピン（0.5mm）で閉じている**ので、ループ面積は
「0.5mm × 80mm ＝ 40mm²」で決まり、**ケーブル全体をどう曲げても
この面積は変わらない**（行きと帰りが一緒に曲がる）。
`FFC_SLACK = 25.0` が暫定値のままでも、**この見積もりには影響しない。**

**これは 2 番の設計判断（GND を SCK の近くに置く／V3V3 の隣に置く）が
効いている**ということでもある。もし GND が 12 番端にあったら
ピッチ 0.5mm × 11 = 5.5mm 離れ、L' は約 2 倍になっていた。

## 7. XIAO 内部側（材料が新しく手に入った分）

`Seeed Studio XIAO nRF52840 v1.1.kicad_pcb` を**同じ S 式解析で機械的に**読んだ
（PDF の目視ではない。依頼の警告どおり、**目視では 2.2µF ×5 を 1 個と
読み違えた前例がある**）。

| 項目 | 実データ |
|---|---|
| 層構成 | **4 層**（F.Cu / In1.Cu / In2.Cu / B.Cu） |
| 3V3 のトレース | **0 本**。**ビアも 0 本** |
| 3V3 の実体 | **In2.Cu 上のベタ 112.4 mm²**（＋F.Cu に 0.5mm² の小片） |
| GND | **F.Cu 340mm² / In1.Cu 341mm² / In2.Cu 340mm² / B.Cu 341mm² ＝ 全 4 層にベタ** |
| 3V3–GND 間の 2 端子部品 | **5 個・全部 2.2µF**（C3 / C6 / C29 / C39 / C41）※機械的に数えた |
| 3V3_OUT パッド（U4 pad12）に最も近いパスコン | **C41 2.2µF・4.65mm** |

**XIAO 内部の 3V3 は「面 対 面」で配られている。**
プレーン対の L = μ₀·h·len/w で、h≈0.2mm・4.65mm 区間なら **0.3 nH 程度**。

| | 単位長あたり | 3V3_OUT までの区間 |
|---|---|---|
| **XIAO 内部**（プレーン） | **約 0.06 nH/mm** | **1 nH 未満** |
| **本機の基板**（0.2mm トレース） | **0.83 nH/mm** | **24〜57 nH** |

> **内部は同じ桁ではなかった。2 桁小さい。**
> 依頼の「内部が同じ桁なら FFC を特別扱いする議論が弱くなる」という
> 見立てに対しては、**内部は桁違いに良い**という答えになる。
> **弱いのは「FFC が特別」のほうで、実際に悪いのは自分の基板の
> V3V3 トレースだった。**

## 8. 未実測のまま残るもの（**机上では決められない**）

| | なぜ机上で決まらないか |
|---|---|
| **FFC の実 L'（0.6〜1.05 nH/mm の幅）** | uxcell 品の Z₀/C の公表値が無い。Würth 品の値で代用している。**確定には LCR/TDR が要る** |
| **コネクタ自身の寄与** | ZIF コネクタの接点〜パッドの L。データシートに記載が無く、見積もりに入れていない（数 nH 程度と推定するが**根拠なし**） |
| **3V3 の実リプル** | **オシロが要る**（`provisional-values.md` と同じ制約）。#40 から継続 |
| **595 の実 t_r** | 2〜3ns はデータシートの typ. 実基板・実負荷での値は未測 |
| マイクロストリップ式の h | 2 層 FR4 1.6mm を仮定。JLCPCB の実スタックで h が変われば ±20% 動く（桁は動かない） |

**いずれも「150nH の桁」を覆さない。**幅を全部悪い側に振っても
（FFC 1.05nH/mm ＋ h=1.6mm ＋ コネクタ 10nH）約 190nH で、
§5 の分流比 58:1 は 45:1 になる程度。**結論は変わらない。**
