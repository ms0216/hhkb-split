# 電源スイッチは基板に載せず、ケース背面のパネルに付ける

**日付**: 2026-08-08
**状態**: 決定（利用者が選択）。**部品は 2026-08-12 に差し替わった**（下記）

> ⚠️ **この記録の中の「C&K OS102011MA1QN1」は、もう本番の部品ではない。**
> 2026-08-12 に利用者が **SS12D01G4-G（秋月 112723）** に決定した。
> **方式（基板に載せず、壁のポケットへ落とし込んでリード線で繋ぐ）は
> そのまま**で、部品だけが替わっている。C&K は端子が横に出る右アングル、
> SS12D01G4-G は基板に垂直なストレートだが、**この設計はスイッチを基板に
> 載せないので、その違いは効かない。**寸法は shopping-list.md と
> open-gaps #18 を見ること。

---

## 1. なぜ決める必要が生じたか

**発注前の部品選定で、そもそも操作できない場所にあると気づいた。**

`SW_PWR`（電源スライドスイッチ）は、電子部品の帯（段と段の間・基板の裏面）に
置かれていた。上はプレートとキーキャップ、下はケースの床。
**ケースを開けないと入切できない。**

| 確かめたこと | 結果 |
|---|---|
| `gen_case.py` に開口があるか | **無い** |
| 組み立て干渉検査が見ているか | **見ていない** |
| `PLACE` のコメント | 「手前の帯に電源。手が届く側に置く」と書いてあったが、実際は左右とも帯 0（奥）。**コメントが実態と食い違っていた** |

**DRC は 3 基板とも 0 件だった。**配線の正しさを機械で検査しても、
この種の誤りは見つからない。見つかったのは「実部品を選ぼうとしたとき」だった。

## 2. 実機はどうなっているか

参考写真 `97_03.jpg`（背面）を見た。左から
**「電源／Bluetooth ペアリング」の丸いプッシュボタン**、中央に電池ボックス、
右に USB。**実機の電源は背面にあり、丸いプッシュボタン**である。

## 3. 決めたこと

**背面パネルに付け、リード線で基板のランドへ繋ぐ。**
基板側は電池ボックスと同じ「ランド 2 個」で受ける。

### 3-1. なぜ基板に載せないのか

**基板の後端からケース背面まで 23.3mm ある。**

| | y |
|---|---|
| 基板の後端 | +48.7 |
| 本体の後端 | +54.0 |
| コブの外側（背面） | +72.0 |

**基板の上のどこに置いても背面には出せない。**「基板に載せる」という
前提自体が誤りだった。電池ボックスがすでにリード線＋ランド方式なので、
同じ形にすれば新しい仕組みは要らない。

### 3-2. なぜスライドスイッチか（実機は丸ボタンなのに）

背面パネルに使える枠を測った。

| | 使える幅 | 奥行 | 高さ |
|---|---|---|---|
| **左** | **10.6mm** | 15.6mm | 15.5mm |
| 右 | 43.9mm | 15.6mm | 15.5mm |

**左が律速。**電池はケース内寸まで 0.2mm、子基板は 0.8mm しか余っておらず、
どちらもずらせない。

調査の結果、**この枠に入る市販品は限られる**と分かった。

| | 実測 | 判定 |
|---|---|---|
| 耳つきパネル取付スライド | 全高 16.2〜19.0mm | 高さで不可 |
| 丸型プッシュロック（M8 級） | パネル裏 18.5mm 以上 | 奥行で不可 |
| **基板実装用の超小型スライド** | 8.60 × 4.40 × 約4.70mm | **収まる** |

丸ボタンは直径がそのまま幅を食うので、10.6mm の枠では不利。
スライドは細長いので**縦向きに置けば幅方向が細くて済む**。

**失うのは見た目の一致だけ。**実機のボタンはソフト電源／ペアリング兼用で、
こちらの「電池を機械的に切る」とは**もともと機能が違う**。
入切が目で分かる点はむしろ有利。

### 3-3. 選んだ部品

**C&K OS102011MA1QN1**（Digi-Key JP / RS JP・約 ¥120）。
[データシート](https://www.ckswitches.com/media/1428/os.pdf)で確認。

| | |
|---|---|
| 本体 | 8.60 × 4.40mm、奥行 約 4.70mm（データシート I-42） |
| 定格 | 0.1A @ 12VDC（負荷は 15mA） |
| 接点抵抗 | 20mΩ 以下 |
| 寿命 | 10,000 回 |
| 端子 | PC マウント（スルーホール）。リード線を半田付けする |
| アクチュエータ | 黒 POM・ストローク 2.0mm |

耳が無いので、**3Dプリントのポケットへ落とし込んで固定する。**

## 4. 覆す前に読むこと

### 4-1. 「基板に戻す」は不可

23.3mm の隔たりは、基板を後ろへ伸ばさない限り消えない。
基板を伸ばすとケースの前後寸法（実機再現の対象）が変わる。

`test_no_user_operated_part_is_sealed_inside` が、基板へ戻すと落ちる。

### 4-2. 「丸ボタンにする」なら枠を確かめてから

左の枠は幅 10.6mm。市販の M8 プッシュロックは胴径 10mm・パネル裏
20〜25mm で、**奥行で入らない**。枠を広げるには電池か子基板を動かす
必要があり、どちらも余裕が 1mm 未満。

### 4-3. 接点は銀メッキ。金の標準品は無い

データシートの型番表に**接点材質の選択欄が無い**。掲載型番はすべて
標準品＝銀メッキで、金は特注（「Gold plate - Contact customer service」）。
**「金メッキの型番を選ぶ」という選択肢は存在しない。**

3.0V・1mA 未満ではアーク放電が起きず、硫化膜が破壊されずに堆積して
数か月〜数年で接触不良になりうる。

**受け入れる理由は「交換できる」こと。**このスイッチは基板に載っておらず、
リード線 2 本で繋がっているだけなので、劣化しても基板に触らず交換できる。
スライド式で接点を擦る点も効く。

**経年劣化は立ち上げ試験では測れない**（数か月〜数年かかる）。
新品の接触抵抗だけは届いたときにテスターで測る。

（外部の調査報告はこの部品を「金メッキ」と断定していたが、
データシートで確かめたところ標準は銀だった。報告は寸法の軸も
取り違えており、アクチュエータ色も誤っていた。**外部の情報も
突き合わせること。**）

## 5. 実機との差（[open-gaps](../open-gaps.md) に記録）

| | 実機 | この設計 |
|---|---|---|
| 形式 | 丸いプッシュボタン | スライドスイッチ |
| 機能 | ソフト電源／ペアリング兼用 | 電池の機械的な切り離し |
| 位置 | 背面の左端 | 背面の空き（左は中央寄り、右は左寄り） |

**差があること自体は悪くない。**機能が違う以上、同じ部品にはできない。
