## 上下の合わせ（`BOTTOM_*`）

壁の下端 2.4 は外皮 1.2 だけを残し、その上（z = 2.4〜3.6）で内側へ 45° に広がって
壁 2.4 になる。底板（外形から 1.3 内側の平板）は外皮の内側に真下から入り、上の
外周の角がこの斜面に当たって止まる。打鍵の力は底板 → 斜面 → 壁。ネジは底板を
斜面へ引き付けるだけ。継ぎ目は底面の外皮の下端の線だけ。

最初は底板側も 45° に落として斜面どうしで載せる形だったが、手前のネジの頭
（縁から 0.05）が斜面と重なった。斜面を底板の上（z ≥ 2.4）へ上げて解決。

## プレートの通り道と壁の厚み（`BEZEL_WALL` 1.2）

プレートは真下から壁の間を通るので、通り道（手前と左右の壁のプレートより下）の
厚み ＋ ベゼルの縁の掛かり ＝ 左右の余白 3.125 − 逃げ 0.1 − 開口の隙 0.725 ＝ 2.3 で
固定される。壁 2.4 だと掛かりが −0.1 で左右を押さえられない。壁 1.2・掛かり 1.1 にし、
壁の内側の 1.2 は底板から立てたリブ（手前の角の丸みからコブの手前まで。内縁側は
子基板の手前まで）が埋めてプレートを受ける。ベゼルの縁（プレートの上）とコブの壁は
2.4。**代償**: プレートより下の側壁が 1.2 の壁 ＋ 1.2 のリブの 2 枚重ねになり、
1 枚の 2.4 より横の曲げに柔らかい（内側へ押される力はリブが受ける）。
配分の候補: 壁 1.4・掛かり 0.9／壁 1.6・掛かり 0.7。

## 中身の出し入れ（INSERT_PATH は上シェルに対して）

底板を外し、下から: 電池蓋 → 電池箱 → 子基板（手前へ抜いてから下）→ 電源スイッチ
（受け箱から手前へ抜いてから下）→ プレート＋基板（真下）。

## 設計中に間違えたこと（実寸で確かめる前に「できる」と言った）

- 子基板の柱を天井から垂らす → プレートと基板を貫通する。底板の柱のまま
- 電源スイッチを下から押し込む → ツマミが奥壁のスロットを通れない。底板を外した
  状態で中から奥へ押し込み、底板の止めブロックで手前を止める
- 奥の柱を y=58.3 に置く → スイッチの端子・線の先端（60.7）に 0.18mm³ 当たる。56.5 でも、
  スイッチを外すのに手前へ 4.4 動かすと当たる。52.3（基板の奥縁の奥、プレートと受けの
  壁に切り欠き）へ
- 底板側の斜面 → 手前のネジの頭と重なる（上記）
