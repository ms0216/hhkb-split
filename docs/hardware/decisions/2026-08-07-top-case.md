# 上ケース（ベゼル）を足し、ネジを外周へ移す

**日付**: 2026-08-07
**状態**: 決定（実装中）

---

## 1. なぜ

**2 つの問題が同じ原因から出ていた。**

| | 内容 |
|---|---|
| [手前端が実機と 5.2mm 違う](../open-gaps.md#1-手前端の高さベゼルが無い) | 実機はキーが窪んだトレイの中にあり、ベゼルが 5.2mm 立つ |
| [ネジ 14 本中 9 本がキーキャップの下](../open-gaps.md#8-取付ネジ-14-本中-9-本がキーキャップの下にある-重大) | 上から留めるしかないため |

原因は「プレートがそのままケースの天板」という構造。上ケースを足すと
両方同時に解ける。**実機が上ケース構造なのは、おそらく同じ理由。**

副次的に、ネジ頭が打鍵面から消え、将来ガスケットマウントへの道も残る。

---

## 2. 決まった寸法（すべて確認済み）

上下方向は「実機の手前端 17mm」から、前後方向は「キーキャップに
ドライバーが当たらないこと」から決まる。

```
        ┌─ ケースの縁            y = ±54.000
        │ ┌─ プレートの縁        y = ±52.400
        │ │   ┌─ 壁の内面        y = ±51.600
        │ │   │ ┌─ 上ケースの開口 y = ±49.125   （ベゼルの幅 4.88mm）
        │ │   │ │ ┌─ 基板の縁     y = ±49.000
        │ │   │ │ │  ┌─ キャップの縁 y = ±47.100
        ▼ ▼   ▼ ▼ ▼  ▼
```

| 項目 | 値 | 決まり方 |
|---|---|---|
| 上ケースの壁 | **1.6mm** | 2.4mm だとプレートとの重なりが 0.23mm しか取れない |
| 上ケースの開口 | キー領域＋**1.5mm** | キャップとの隙間 2.03mm。1.0mm では重なりが足りない |
| プレートとの重なり | 1.02mm | 押さえるのに要る最小 |
| **ネジのボス中心** | **y = ±51.5** | 下の 4 条件が同時に成立する唯一の帯 |

### ボス y=±51.5 が満たす条件

| 条件 | 値 |
|---|---|
| ネジ頭 φ3.8 がベゼルの幅に収まる | 49.60〜53.40 ⊂ 49.125〜54.00 |
| **基板が無加工で済む** | 基板の縁 49.00 ≤ ボスの内端 49.00 |
| キャップからドライバーが入る | 2.50mm |
| ボスは壁と一体（内へ 2.60mm 出る） | 壁の内面 51.60 → ボス 49.00 |

プレートだけは縁に**切り欠き**が要る（逃げ穴 50.30〜52.70 がプレートの縁
52.40 を越えるため）。基板と違い、外注ではなく自分で発注する FR4 なので
切り欠きは問題にならない。

### なぜ左右の辺にはネジを置かないか

左右の余白は 4.125mm しかなく、壁 2.4mm を引くと 1.7mm。
**ボスもネジ頭も入らない。** 前後の辺（6.375mm）と隅だけに置く。
プレートは連続したベゼルで押さえるので、辺の中央が浮くことはない。

## 3. 高さ

| | 値 |
|---|---|
| ベゼル上面（前縁） | **17.5mm** ← 実機の手前端 17mm |
| プレート上面（前縁） | 11.78mm ← ホーム段 31.6mm から逆算 |
| 差（ベゼルの立ち上がり） | 5.72mm ← 実機は 5.2mm |

**プレートの高さは動かさない。** キートップの高さは実機と一致済みで、
そこが最優先。ベゼルはその上に足す。

---

## 4. 締結

```
   上ケース（ベゼル）      ← ネジ頭はここに座ぐる
   ─────────────
   プレート               ← 切り欠きでボスを逃がす
   スイッチ               ← プレートと基板を機械的に繋ぐ
   基板                   ← 無加工。スイッチで保持される
   ─────────────
   下ケース（トレイ）      ← 壁と一体のボスにネジが入る
```

- ネジは**上ケースからボスへ**。キー領域には 1 本も入らない
- 基板はプレートとスイッチで一体になり、上下ケースに挟まれる
- 本数は前後の辺に片側 6 本（隅 4 ＋ 前後の中央各 1）を予定

---

## 5. 併せて入れるもの

| | |
|---|---|
| **RESET の穴** | 子基板の脇に φ2。ファームを壊しても分解せず復旧できる |
| ネジボスの肉厚 | φ5.0（肉厚 1.65mm）のまま。熱圧入インサートを使うなら φ5.6 へ |
| 公差クーポン | プリンタが使える週に 1 枚刷って `CLEARANCE` を確定させる |
