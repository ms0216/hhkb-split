# XIAO は子基板に載せ、奥の壁に立てる

**日付**: 2026-08-07
**状態**: 決定（利用者が選択）

---

## 1. なぜ決める必要が生じたか

本体基板に電子部品を置こうとして、**置き場所が無いことが分かった。**

HHKB のキー配列は基板をほぼ埋め尽くす。実測した空きは次のとおり。

| 場所 | 空き | 入るもの |
|---|---|---|
| 基板奥の帯（裏面） | **10.3mm** | 74HC595（6.4×10.4mm）と受動部品 |
| 基板奥の帯（表面） | 5.9mm | 何も入らない（スイッチのピン穴が来る） |
| 基板手前の帯 | 21×18mm が 1〜3 箇所 | XIAO は入るが USB が手前に出る |

導出:

```
プレート上下余白 6.375mm ＋ キーピッチ/2 9.525mm − PCB 内側 3.0mm = 12.90mm
  表面: 12.90 − 7.0（スイッチ本体） = 5.90mm
  裏面: 12.90 − 2.6（ソケット）      = 10.30mm
```

**XIAO は 21×17.8mm。奥の帯には物理的に入らない。**

> **⚠️ 上の 10.3mm は当時（PCB 内側 3.0mm）の数字（2026-08-11 追記）。**
> その後 `PCB_INSET_Y` が 3.0 → 5.3mm になり、奥の帯は **3.40mm**。
> **結論（入らない）はむしろ強化された**が、この表の数字を現在値として
> 別の判断に使わないこと。

## 2. 検討した案

| 案 | USB-C の出口 | 追加部品 | 判断 |
|---|---|---|---|
| **子基板を奥の壁に立てる** | **奥面（HHKB と同じ）** | コネクタ 2 個＋ケーブル | **採用** |
| 手前の空きに寝かせる | 手前面か内側面 | なし | HHKB と違う。打鍵時に手の前へケーブルが来る |
| 奥の帯にヘッダでぶら下げる | 奥面 | ヘッダのみ | パッドとスイッチのピン穴の隙間が 0.03〜0.3mm。発注後に判明する類の手戻り |
| ケースを 15mm 深くする | 奥面 | なし | 奥行 108mm という HHKB 再現の根幹を捨てる。却下 |

採用理由は **USB-C の位置が HHKB と同じ奥面になること**。
副次的に、XIAO の抜き差し・書き換え・故障時の交換がすべて楽になる。
JLCPCB は 5 枚無料枠があるので、基板が 1 種増えても費用はほぼ変わらない。

## 3. ケーブルに通す信号（12 本）

行は MCU 直結という制約（[keyscan の決定](2026-08-07-keyscan.md)）があるため、
**5 本の行がすべてケーブルを渡る。** これが本数を決めている。

**出所は `tools/circuit.py` の `J_DB` / `J_MAIN`。**この表はそこから写した
ものなので、`test_the_cable_pinout_table_matches_the_circuit` が
1 ピンでも食い違ったら落ちる。**手で直さない。**

| # | ネット | XIAO のピン | 役割 |
|---|---|---|---|
| 1 | `CS` | D7 | 74HC595 のラッチ |
| 2 | `GND` | GND | |
| 3 | `SPI_SCK` | D8 | SPI クロック |
| 4 | `ROW4` | D9 | **元 MISO。**アンテナ直下の配線を減らすため右列へ移した（open-gaps #23・2026-08-11） |
| 5 | `SPI_MOSI` | D10 | SPI データ |
| 6 | `V3V3` | 3V3 | 本体基板の電源部から供給。BAT 端子は使わない |
| 7 | `VBATT_SENSE` | D0 | 電池電圧のセンス（分圧後） |
| 8 | `ROW0` | D1 | |
| 9 | `ROW1` | D2 | |
| 10 | `ROW2` | D3 | |
| 11 | `ROW3` | D4 | |
| 12 | `GND` | GND | |

**並び順を決めたのは配線の都合。** 子基板では FFC が手前、XIAO のパッドが
左右 2 列にある。手前から上がる配線は、近いパッドへ行くものほど外側を通す
必要があり、ピン順がそれと逆だと交差する。**最初の並びでは 6 箇所が短絡した。**
いまは右群 (1-6) が右列（D7,D8,D9,D10,3V3）を前→奥の順、
左群 (7-11) が左列（D0..D4）を奥→前の順。**ROW4 だけ右群にいる**のは、
行き先を右列の D9 へ移したため（open-gaps #23・2026-08-11。左群のままだと
横枝が左群の縦線を 8 箇所で横切ることを DRC で確認した）。

その制約の中で、**最も速い SCK (3) を GND (2) の隣に置いた。**戻り電流が隣を
通るのでループ面積が小さくなり、放射も受信も減る。

**両端を GND にはできなかった。**12 番は GND だが、1 番は CS になっている。
上の配線順の制約が先に決まるため、両端を GND にすると交差が戻る。CS は
1 スキャンに 1 回しか動かない最も遅い信号なので、端に置く害が最も小さい。
（この文書は以前「両端を GND にしてある」と書いていたが、**事実と違った。**
表そのものも旧い並び順のまま残っていた。）

### コネクタ

**12 ピン・0.5mm ピッチの FFC（フレキケーブル）コネクタ**を両基板に置く。
型番は `Hirose FH12-12S-0.5SH`（JLCPCB 在庫あり・$0.68）。
`test_the_connector_spec_matches_the_board` が実基板と照合する。

- 厚みが 1mm なので、ケースの限られた高さを食わない
- 12 本が 6mm に収まる

（この節は以前「1.0mm ピッチ」「12 本が 12mm」と書いていた。**実基板は
最初から 0.5mm ピッチだった。**本数だけを見る検査があったので通っていた。）
- JLCPCB の実装工程で載る（利用者が半田付けするのはソケットだけ、という方針を保てる）
- ケーブルは既製品

**入手できなかった場合の代替**: 12 ピン 2.54mm ピンヘッダ＋リボンケーブル。
高さを 8.5mm 食うので、ケース内の余裕を確認してから。

## 4. どちらの基板に何を載せるか

### 本体基板（裏面・奥の帯）

| 部品 | 個数 | 置く理由 |
|---|---|---|
| 74HC595 | 左 1 / 右 2 | **駆動する列のすぐ隣。**配線が最短になる |
| 0.1µF パスコン | 595 の個数ぶん | 各 595 の VCC 直近 |
| 100µF バルク | 1 | 電源部 |
| ショットキー SB240LES | 1 | 逆流防止＋ USB 時の電池切り離し |
| 1MΩ ×2 | 1 組 | 電池電圧の分圧 |
| スライドスイッチ | 1 | 電源 |
| 電池線のランド | 2 | 単3×2 の電池ボックスから |
| FFC コネクタ 12P | 1 | 子基板へ |

### 子基板

| 部品 | 個数 |
|---|---|
| XIAO nRF52840（ピンヘッダで着脱可） | 1 |
| 0.1µF パスコン | 1 |
| FFC コネクタ 12P | 1 |
| ケース固定用の穴 | 2 |

**子基板は奥の壁の内側に立てる。** USB-C は壁の切り欠きから覗く。
HHKB と同じく、少し奥まった位置になる。

---

## 5. ケースへの影響

| 変更 | 内容 |
|---|---|
| 奥の壁に USB-C の切り欠き | 幅 10mm × 高さ 5mm 程度。プラグの外形が入る大きさ |
| 子基板の取付ボス 2 本 | 奥の壁の内側 |
| 電池室の位置 | 子基板と干渉しないこと。奥の壁から 25mm は空ける |

**ケースの外形寸法（奥行 108mm・手前端 17.5mm・傾斜 7.3°）は変えない。**
これが変わらないことが、この案を採った理由そのもの。
