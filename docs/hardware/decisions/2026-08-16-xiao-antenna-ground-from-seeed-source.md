## この案件（#23）にとって何を意味するか

**#23 は一般論の「全層で 5〜10mm の禁止域」を指針にしてきた。**
**AN3216 を実際に量産している設計者が取っているのは、本体の縁から 1.30mm
（外形から 3.14mm）で、5mm ではない。**

| | 距離 |
|---|---|
| 一般論の指針 | 全層 5〜10mm |
| **Seeed の実装（AN3216・4 層）** | **アンテナ本体の縁から 1.30mm・全層同一** |
| いまの設計（出荷構成・直付け） | 本体基板まで **5.24mm**（`test_the_antenna_keeps_its_distance_from_the_main_board`） |

⚠️ **これは「5.24mm あるから安全」という結論ではない。**性質が違う:

- Seeed の 1.30mm は**同じ基板の中の、面内方向の**銅の逃げ。
  地板はアンテナの給電の一部として設計に織り込まれている
  （AN3216 のようなチップアンテナは地板を放射体として使う）
- #23 が問題にしているのは、**別の基板の大きな GND 面が、アンテナの
  斜め上に 5.24mm で覆いかぶさる**こと。これは Seeed が想定した
  「モジュールの外側は空いている」という前提を壊す側の話

**読みが変わるのはここ:** #23 の「上 4mm・下 1.6mm では、どう対策しても
指針 5〜10mm を満たせない」という記述は、**満たすべき基準を過大に見ていた
可能性がある。**Seeed 自身が 1.30mm で製品を出しているので、
**5mm を割ったこと自体は即座に不合格を意味しない。**

**それでも手 0 は要る。**基板の面内で銅を抜くことと、外部の金属面が
近づくことは別の物理で、机上のどちらの数字からも dB は出ない。
**#23 を閉じるのは実測だけ。**

## 副産物: モジュールの外側に何を置いてよいか

Seeed 自身は **アンテナ端の基板外形から 3.14mm を全層で空けている**が、
**基板はそこで終わっている**（外形 x=138.0236 で、アンテナは 0.271mm 内側）。
つまり **Seeed は「モジュールの外の空間」については何も保証していない。**
XIAO のデータシートが「金属で覆うな」としか書けないのはこのため。

**→ ケース側でアンテナの外側にどれだけ空けるべきかは、この資料からは決まらない。**
そこが手 0 で測る対象そのもの。
