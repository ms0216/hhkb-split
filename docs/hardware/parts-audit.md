# 部品の棚卸し — 効く条件と、何で確かめたか

**2026-08-08。**CLAUDE.md「決める前に通す手順」を、既に選んだ部品すべてに
遡って当てた。**選ぶときにこれをやっていなかったので、遅れて 2 回覆した。**

読み方:

- **外** … データシート・JLCPCB の API・実測など、外の事実で確かめた
- **未** … まだ確かめていない。**「たぶん大丈夫」は未に入れる**

## 1. シフトレジスタ SN74LVC595APWR（C52287685）

| 効く条件 | 確かめたか | 値 |
|---|---|---|
| 動作電圧の下限 | **外** | 1.1V。レール下限 1.83V の内側 |
| 動作電圧の上限 | **外** | 3.6V。レール最大 2.90V（USB 時 3.3V）の内側 |
| 1.8V での出力電流 | **外** | ±4mA。列の駆動に十分 |
| ピン配置 | **外** | 標準の 595。ZMK の `zmk,gpio-595` がそのまま使える |
| **1.8V での最高周波数** | **外** | **fclock 104MHz @ 1.8V（−40〜125℃ 保証）。**SPI 4MHz に対し余裕 26 倍 |
| **出力降下 VOH** | **外** | **IOH=−100µA で VCC−0.2V。**0.05V と推定していたのは 4 倍の誤りだった |

**74HC595 から替えた理由**は動作電圧の下限（2.0V）。レールが打ち止めで
1.83V まで下がるので規格外だった。→ `test_every_ic_runs_down_to_the_cutoff`

## 2. マトリクスのダイオード BAT46W（C54110）

| 効く条件 | 確かめたか | 値 |
|---|---|---|
| **走査電流での VF** | **外（保証・動作点）** | **≦0.25V @ IF=0.1mA** |
| **低逆電圧での IR** | **外（保証・動作点）** | **≦0.3µA @ VR=1.5V** |
| 必要なレール | 計算 | (0.30+0.05)/0.3 = 1.17V。**マイコンの 1.80V が律速** |
| ゴーストの余裕 | 計算 | 余裕 190mV に対し、行 9 個同時押しで 35mV（25℃） |
| 高温 | **外** | 60℃ では 5µA。**5 個以上の同時押しで余裕を割る**（机上の 25〜30℃ なら問題ない） |
| 接合容量 | 計算 | 20pF ×9 = 180pF。列切替後 2.31µs で VIL。SPI 転送 4.0µs 以上あるので間に合う |
| フットプリント | **外** | SOD-123。1N4148W と同じで基板は変わらない |
| 在庫 | **外** | 25,893 |

**在庫 5,000 超の SOD-123 ショットキー 29 件と、BAT47/48/49/54/85・
1SS 系・NSR・RB751・PMEG・MBR05xx を当たった結果、VF と IR を両方
動作点で保証しているのは BAT46W だけ。**

**バックアップは 1N4148W（C81598・Basic）。**戻すときは
`circuit.MATRIX_DIODE_VF` を 0.55 に戻す。打ち止めは 1.20V/本 に上がり、
マトリクスがマイコンより先に落ちる壊れ方に戻る。

## 4. バルク 100µF CL31A107MQHNNNE（C15008）

| 効く条件 | 確かめたか | 値 |
|---|---|---|
| **DC バイアス後の実効容量** | **計算で無関係と判明** | 6.3V 品に 3V で半減するが、**結論が容量に鈍感**（下記） |
| 耐圧 | **外** | 6.3V。レール最大 2.90V の内側 |
| パッケージ | **外** | 1206。実基板と一致 |

**送信中の降下は「電流 × 電池の内部抵抗」で決まり、容量では消せない。**
100µF → 50µF → 25µF と減らしても、300µs のバーストでの降下は
19.5 → 22.1 → 22.5mV。定常値 22.5mV に対して**容量ゼロとの差が 3mV**。

余裕 `MCU_MARGIN` は 100mV なので成立する。
`test_the_margin_covers_the_transmit_droop` が見張る。

## 8. ホットスワップソケット CPG151101S11-2（C49352235）

| 効く条件 | 確かめたか | 値 |
|---|---|---|
| **フットプリント適合** | **外（推奨ランド図）** | 6.35 / 2.54 / φ3.00 / 2.55×2.5mm。**KiCad の実物と一致** |
| **最低使用電圧** | **外** | **2V DC min（錫めっき）。いまのレール下限を決めているのはこれ** |
| 最低使用電流 | **外** | 10µA min。走査は約 100µA なので内側 |
| 接触抵抗 | **外** | 100mΩ max |
| 寿命 | **外** | 5,000 回の挿抜 |
| 在庫 | **外** | 37,697（-16 は 283,792・同価格・**色違いだけ**） |

**金めっき品は JLCPCB に無い。**CPG151101S11 の全変種（-1/-2/-4/-16）を
確認した。-16 は筐体が紫、-2 は白。**接点はどちらも錫、2V min も同じ。**

**この 2V がレールの下限（2.00V）＝ 打ち止め 1.20V/本 を決めている。**
マイコン（1.80V）やマトリクス（1.67V）より厳しい。**電池の末尾 1 割ほどを
捨てることになるが、保証範囲の外で使うよりよい。**

## まだ確かめていないもの

**無し。**（2026-08-08 に全項目を閉じた）

閉じ方の内訳:

| 項目 | どう閉じたか |
|---|---|
| マトリクスのダイオードの VF | **部品を替えた**（BAT46W。保証値で詰まる） |
| バルクの実効容量 | **計算で無関係と判明**（容量を倍にしても 3mV） |
| 595 の 1.8V での fmax | **データシート**（104MHz。余裕 26 倍） |
| 595 の出力降下 | **データシート**（VCC−0.2V。推定の 4 倍だった） |
| ソケットのフットプリント | **推奨ランド図と KiCad が一致** |
| ソケットの最低使用電圧 | **制約に追加**（2V。いまのレール下限を決めている） |
| ADC の取得時間 | **ZMK が 40µs を設定済み**。対応不要 |

**残っているのは「実測でしか埋まらないもの」だけ**（`SCHOTTKY_VF`・
`BLE_TX_CURRENT`・`BATT_ESR_END`。いずれも Task C4 で測る。
[provisional-values.md](provisional-values.md)）。
