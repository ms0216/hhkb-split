**切るだけでは終わらない。**ワイヤーは平らな針金ではなく、**両端が L 字に
曲がっていて、その L 字が挿子（ステム）に刺さる**（モデルの bbox が
2u/3u とも 奥行 10.75mm・高さ 7.63mm あるのがその証拠。
**幅だけが 25.48 → 39.70 と違い、奥行と高さは同じ**＝
端の曲げ形状は共通で、**中央の直線部の長さだけが違う**）。

6.25u を切ると「片側だけ L 字が付いた棒」が 2 本できるだけで、使えない。
**切った側に L 字を作り直す＝曲げ加工が要る。**

曲げるとなると難しさは別物になる:

| | |
|---|---|
| 材質 | ピアノ線／ステンレス鋼線。**硬く、狙った角度で止まらない**（スプリングバック） |
| 要る精度 | 支点間 38.10mm。**左右非対称だとキーが斜めに沈み、引っかかる** |
| 直角の質 | L 字が甘いと挿子から外れる。**ガタつき・異音の原因** |

**海外の自作キーボード掲示板（KeebTalk・deskthority）を見たが、
「自作した」という完成報告が見つからない。**専用の曲げ工具
（Du-Bro 480 E/Z Bender 等）を挙げている人はいるが、
**「試していないので分からない」と本人が書いている。**
スタビにルブを塗るような細かい改造を日常的にやっている界隈で
**誰も完成させていない**のは、割に合わないことの傍証。

→ **やめたほうがよい。**ワイヤー 1 本は $1〜4。**送料のほうが高い**くらいで、
時間と失敗のリスクに見合わない。**買うこと。**

**現実的な買い方**: 2u は遊舎工房で 2 個（¥440・条件を満たすことが確実）。
**3u は AliExpress の「2u 3u 6u 6.25u 7u」セット**を先に注文（納期が長い）。
届かない・合わない場合の保険として、**2u をもう 2 個買ってワイヤーだけ
3u 用にする**手が残る。

**⚠️ 基板の発注をせき止めない。**穴は業界標準どおりに開いており、
スタビは後から買い直せる。
