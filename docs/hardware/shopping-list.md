### スイッチを買うときに見ること（2026-08-23・利用者の質問から）

**ソケットは JLCPCB が実装してくる**ので、届いた基板にスイッチを**手で挿す**
だけ（はんだ付けではない）。**合わなければ挿さらないだけで、基板は無傷。**

**見るのは金属端子の位置だけ。**いまのソケット（CPG151101S11）が受けるのは:

| | キー中心から |
|---|---|
| 金属端子 1 | **(−3.81, −2.54) mm** |
| 金属端子 2 | **(+2.54, −5.08) mm** |
| 2 本の間隔 | **x 6.35mm / y 2.54mm**（Cherry MX の規格値。**斜めにずれて並ぶ**） |

#### ⚠️ 「MX 互換」だけでは足りない

**ステムの形（キーキャップ用）と金属端子の位置（ソケット用）は独立している。**
同じ「MX 互換」という言葉が、スイッチの説明では端子を、キーキャップの
説明ではステム受けを指す。**別のものを同じ言葉で呼んでいる。**

**いちばん危ないのは Kailh Choc V2。****MX 互換の十字ステムを持つ**ので
「MX 互換」と書かれていることがあるが、**端子が全く別で刺さらない。**

#### 判定は「高さ」でつく

| | 高さ | |
|---|---|---|
| **MX（正解）** | **約 14mm** | 本体も約 14mm 角 |
| **低背**（Choc V1/V2・Gateron KS-27・Cherry MX Low Profile） | **約 8.8mm** | **明らかに薄い。刺さらない** |

**5mm 以上違うので写真でも一目で分かる。**「薄い」と感じたら低背。

#### チェックリスト

1. **高さ約 14mm**（薄いものは全部だめ）
2. 「Cherry MX 互換」＋「**ホットスワップ対応**」の記載
3. 「低背」「ロープロファイル」「Low Profile」「Choc」の語が**無い**こと
4. 光学式・磁気式（Hall Effect）・Alps・Topre は**別物**

## スタビライザーの選び方（2026-08-31・**3u 問題は設計変更で解決した**）

### ★ 結論: **2u を 4 個買うだけ。**3u は要らない

**元は 2.25u ×2（左Shift・Enter）＋ 3u ×2（スペース）だったが、
3u のスタビが国内で買えないことが分かったので、
2026-08-31 に**スペースキーを 3u → 2.75u に変更**した（利用者の判断）。
Cherry 規格では **2u / 2.25u / 2.5u / 2.75u が同じスタビ**（支点 ±11.938）なので、
**4 個すべて「2u」で足りる。**

| 要るもの | 数 | 使う場所 |
|---|---|---|
| **Cherry MX PCB マウント 2U** | **4** | 左Shift(2.25u)・Enter(2.25u)・L-Space(2.75u)・R-Space(2.75u) |

### 仕様にこの 3 つが書かれていれば OK

| # | 条件 | 仕様欄の書かれ方 | これを外すと |
|---|---|---|---|
| 1 | **PCB マウント** | 「PCB Mount」「PCBマウント」「基板取り付け」 | **プレートマウントは付かない。**基板の穴を使わない |
| 2 | **Cherry MX 互換** | 「Cherry MX」「MX 互換」「Cherry compatible」 | Choc / ロープロ / Alps は穴が別 |
| 3 | **2U** | 「2U」 | — |

**「Cherry MX PCB マウント 2U」と書いてあれば挿さる。**
ブランド（Durock / Everglide / Gateron / ノーブランド）は問わない。安い互換品でよい。

⚠️ **「2.25u 用」「2.75u 用」という商品は存在しない。**探しても見つからないのは
規格上 2u と同じ部品だから。上流フットプリントの説明文にもそう書いてある

### 記録: なぜ 3u をやめたか（2026-08-31）

**3u は国内で買えなかった。**遊舎工房のスタビ一覧に 3U 無し。
TALP は DUROCK 3U V3 の商品ページが **404**（終売と見られる）、
スタビ一覧も在庫切れ 2 件で 3U 無し。**Amazon も 3u 無し**（2u/6.25u/7u のみ）。
海外専門店（MechWild $1.00・CannonKeys $3.75/5本 ほか）にはあるが、
**調べた 4 店のうち 3 店が品切れ・1 店が注文停止中**だった。

**「ワイヤーだけ 3u 用に替える」案も検討したが取り下げた。**
ワイヤーは平らな針金ではなく両端が L 字に曲がっており（モデルの bbox が
2u/3u とも奥行 10.75mm・高さ 7.63mm で同じ＝端の曲げは共通、
中央の直線部の長さだけが違う）、**切るだけでは「片側だけ L 字が付いた棒」に
なる。**曲げ直しにはピアノ線の曲げ加工が要り、KeebTalk / deskthority を見ても
**「自作した」という完成報告が無い**（専用工具を挙げる人はいるが本人が
「試していない」と書いている）。

**→ キー幅を 2.75u にするほうが確実。**実機からのずれは片側 4.76mm だけで、
**2u スタビが使える最大の幅**なのでずれが最小。縮めたのは**内側だけ**なので
他のキーは 1 つも動かず、キーどうしの隙間もできない。
