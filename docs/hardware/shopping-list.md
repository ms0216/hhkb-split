# 買い物リスト（一般通販ぶん・2026-08-11 統合）

**JLCPCB へ発注する部品はここに入れない**（それは
[cost-estimate.md](cost-estimate.md) と `tools/jlcpcb_lookup.py --parts`）。
ここは**利用者が一般の通販で買う物**の一覧。

**このリストの作法（#22 の再発防止）:**

- 「電池ボックス 単3×2」のような**種類だけの行を作らない。**型番まで書く。
  型番が未定の行は「**品番未定**」の節に置き、**買う前に決める**
  （CLAUDE.md: 実験用に別品番を買わせない）
- 各行に**出所（決めた文書）**と**届いたら確かめること**を書く。
  確かめる先は [provisional-values.md](provisional-values.md) の定数
- 書き足すとき・買うときは、**出所の文書と突き合わせる**。リストだけを
  信じない（#22 は「箱」とだけ書いたリストが横並び型を買わせた）
