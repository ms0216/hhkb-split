# ベース機（HHKB Professional HYBRID Type-S）の寸法

実機採寸ではなく、公開情報と機械可読な一次情報から確定させたもの。
調査日: 2026-08-05

---

## 1. 外形（PFU 公称値）

**ベース機 PD-KB800WNS = HHKB Professional HYBRID Type-S（英語配列・無刻印・雪）**

| 項目 | 値 | 出典 |
|---|---|---|
| 幅 | 294mm | PFU 公式仕様 |
| **奥行** | **120mm** | PFU 公式仕様 |
| 高さ | **40mm（キートップ上面まで）** | PFU 公式仕様 |
| キーピッチ | 19.05mm | PFU 公式仕様 |
| キーストローク | 3.8mm（Type-S） | PFU 公式仕様 |
| 押下圧 | 45g | PFU 公式仕様 |
| 質量 | 540g（電池含まず） | PFU 公式仕様 |
| 電源 | 単3形乾電池×2本 ／ USB 給電 | PFU 公式仕様 |
| 電池寿命 | アルカリで約3ヶ月 | PFU 公式仕様 |

### 品番による奥行の違い（重要）

| モデル | 奥行 | 電池 |
|---|---|---|
| **HYBRID / HYBRID Type-S（PD-KB800/820 系）** | **120mm** | 単3×2 |
| Classic / PD-KB401 系 | 110mm | なし（USB-C のみ） |

**電池搭載機は 10mm 奥行が長い。** 奥側の電池ボックスのぶん。
他品番の資料から寸法を借りるときは、この差に注意すること。

### 奥行 108mm と 120mm の関係（両方とも正しい）

Tom's Hardware のレビューが逐語で書いている:

> "11.5 inches (292 mm) long by 4.75 inches (120.6 mm) wide (at its widest point
> — without the battery bump, the keyboard is 4.25 inches/108 mm wide)"

つまり本機は**単純な楔形ではなく、奥に電池コブが張り出した形**である。

| 部位 | 奥行 |
|---|---|
| 本体部（電池コブを除く） | **108mm** |
| 電池コブ込みの最大 | **120mm**（PFU 公称）／ 120.6mm（レビュアー実測） |

以前この文書で「奥行 108mm は誤り」と記録したが、**それ自体は誤りだった**。
108mm は実在する寸法で、私が全体奥行と取り違えていただけである。
**設計基準は 120mm（コブ込み）を採る**が、ケース断面は「108mm の本体＋奥のコブ」
として造形する。

## 2. 鍵盤面

| 項目 | 値 | 根拠 |
|---|---|---|
| キーピッチ | 19.05mm（1u） | 業界標準 |
| 鍵盤面の幅 | 15u = **285.75mm** | 全行が 15u であることから |
| ベゼル（左右合計） | 294 − 285.75 = **8.25mm** | 上記の差 |

写真計測で鍵盤面の幅は **286.11mm** と出た（理論値との差 0.36mm）。ピッチを基準にした較正の妥当性はこれで確認できている。

## 3. キー配置（u 単位）

出典は 2 つ。**どちらも実機に基づく一次情報で、完全に一致した。**

1. **QMK Firmware `keyboards/hhkb/ansi/info.json`** — 実機 HHKB 用の置換コントローラー（Hasu 版）のレイアウト定義。機械可読。
2. **Wikimedia Commons `HHKB Pro 2 - keyboard layout editor - final.png`** — HHKB Pro 2 の KLE 図。刻印つき。

| 行 | 構成 | 合計 |
|---|---|---|
| 0 | 1u × 15（Esc, 1〜0, -, =, \\, \`） | 15u |
| 1 | 1.5u(Tab) + 1u × 12 + 1.5u(Delete) | 15u |
| 2 | 1.75u(Control) + 1u × 11 + 2.25u(Return) | 15u |
| 3 | 2.25u(Shift) + 1u × 10 + 1.75u(Shift) + 1u(Fn) | 15u |
| 4 | **余白 1.5u + 1u + 1.5u + 6u + 1.5u + 1u + 余白 2.5u** | 15u |

### 最下段の詳細（当初の想定を訂正）

QMK の定義（x = 左端からの位置、w = 幅、いずれも u）:

```
x=1.5 /w=1     x=2.5 /w=1.5     x=4 /w=6     x=10 /w=1.5     x=11.5 /w=1
```

KLE 図の刻印と突き合わせると:

| 位置 | 幅 | キー |
|---|---|---|
| 1.5 〜 2.5 | **1u** | Alt / Opt（外側） |
| 2.5 〜 4.0 | **1.5u** | ◇ / ⌘（スペース寄り） |
| 4.0 〜 10.0 | 6u | スペースバー |
| 10.0 〜 11.5 | **1.5u** | ◇ / ⌘（スペース寄り） |
| 11.5 〜 12.5 | **1u** | Alt / Opt（外側） |

**訂正2点:**

1. 当初「◇ が 1.5u、Alt が 1u」と想定していたが**逆**だった。外側が 1u、スペース寄りが 1.5u。
2. 左の余白は 1.5u だが**右の余白は 2.5u** で非対称。実機写真でもこの非対称は目視で確認できる。

（どちらのキーが Alt でどちらが ◇ かは DIP SW4 で入れ替わる。物理的な幅の並び「外側 1u / 内側 1.5u」は不変。）

## 4.5. 高さ方向の形状（外部調査で確定）

外部の調査エージェントに依頼して取得し、**一次資料を直接取得して逐語検証済み**。
依頼書は [research-brief-height-profile.md](research-brief-height-profile.md)。

### ケース断面

| 項目 | 値 | 出典 | 信頼度 |
|---|---|---|---|
| 手前縁の高さ | **17mm** | Tom's Hardware 逐語 "0.67 inches (17 mm) thick at the front"。別レビュー(blue-de)は約18mm | 高 |
| 奥縁の高さ | **31.8mm** | 同 "1.25 inches (31.8 mm) thick at the back" | 高 |
| 前後の高低差 | 14.8mm | 上記の差 | 高 |
| 打鍵面の実効傾斜 | **7.3°** | `github.com/fernandodeperto/topre_key` の `key.scad`。`KEYBOARD_ANGLE = 7.3;` にコメント "Angle measured on the HHKB" | 中〜高 |
| チルトスタンド | 0° / 3° / 6° の3段階。**長さの違う脚が2組**あり、その組み合わせで3段階を作る | Tom's Hardware 逐語 "two sets of plastic flip-out feet for three levels of height adjustment"。角度は複数の日本語レビューが一致 | 高（機構）／中（角度） |

**傾斜角の整合性**: 高低差 14.8mm を本体部 108mm で割ると 7.81°、コブ込み 120mm で割ると 7.03°。
実測された打鍵面角 7.3° はこの間に収まる。**3 系統が独立に 7〜8° を指しており矛盾がない。**
設計は **7.3°** を採る。

以前「手前 20mm」を候補値としていたが、実測 2 件（17mm / 約18mm）はいずれも下回る。
**20mm は過大**と判断し、**17.5mm** を設計基準とする。
一方「奥 32mm」は実測 31.8mm とほぼ一致しており、裏取りできた。

### キーキャップの列プロファイル

出典は `github.com/fernandodeperto/topre_key`（OpenSCAD モデル）。
README に "I measured the keys for different rows using a caliper"、
`key.scad` に "Angle measured on the HHKB" とあり、**HHKB 実機のノギス実測**に基づく。
**リポジトリを直接取得して数値を確認済み。**

| 列 | キャップ高さ | 天面の傾き | 備考 |
|---|---|---|---|
| 数字段（Row E） | **10.2mm** | **+2°** | 最も高い |
| QWERTY 段（Row D） | **8.2mm** | **−2°** | |
| ホーム段 ASDF（Row C） | **6.7mm** | **−8°** | |
| ZXCV 段（Row B） | **6.7mm** | **−13°** | |
| 最下段（Row A） | **6.7mm** | **−13°** | |

符号は「正＝奥に向かって天面が上がる」「負＝手前が高く奥へ下がる（＝天面が指の方を向く）」。
ホーム段以下が大きな負角を持つことが、**HHKB の「各キー天面が中央を向く」
シリンドリカル・ステップスカルプチャの正体**である。

**独立した裏付け**: 同モデルはキャップ底面を **18 × 18mm** と定義している。
キーピッチ 19.05mm に対する妥当な値で、実測由来であることを補強する。

**限界**: 個人 1 名のノギス実測 1 系統のみ。**±0.5mm・±1〜2° の誤差を見込む**こと。
また「高さ」がキャップ底面から天面のどこ（背縁か中央か）までを指すかがモデルから
一意に読み取れない。CAD で使う際は背縁と解釈し、試作で検証する。

### ケース断面の実形状（実機写真で確認）

当初この断面を「垂直な前後面をもつ台形」としてモデル化したが、**実機は違った**。
pdweb.jp のレビュー写真 `97_11.jpg`（前縁の接写）で以下を確認した。

| # | 実形状 | 当初のモデル |
|---|---|---|
| 1 | 前面は垂直でなく、**下へ行くほど奥へ傾く**（最前点は上端付近） | 垂直 |
| 2 | ベゼル上面から前面への移行は**大きな R で丸い** | 直角 |
| 3 | 側面の中ほどに**上下シェルの合わせ目**が走る | なし |
| 4 | 合わせ目より下は**内側にさらに絞られ**、底は一回り小さい | なし |
| 5 | キーは**窪んだトレイの中**にあり、ベゼルのリムがキー面より上に立つ | 平面 |

**数値は目測**（前面の傾き 12°、前縁の R 6mm 程度）。斜めからの写真 1 枚しか
なく、遠近の影響を分離できないため実測ではない。3・4 は表面上の特徴であり
断面形状ではないので、断面図には描いていない。

**設計への影響**: 1・2・5 は手首と手のひらが当たる部分なので使い勝手に効く。
ただし正確な値は得られないため、**試作で詰める**（3Dプリントで刷り直す）。
3・4 は外観のみ。

## 5. 未確定のまま残る項目

外部調査でも取得できなかった項目。いずれも**分割版では自分で決めてよい**か、
**試作で詰める**もので、実機採寸を必要としない。

| 項目 | 影響範囲 | 代替手段 |
|---|---|---|
| 手前縁の断面形状（丸み半径・面取り角） | 手首の当たり | 数値の一次資料なし。**R1〜2mm の丸めから試作**して詰める |
| チルト脚 2 組の長さと支点位置 | 機構再現 | 0°/3°/6° になる長さを幾何から逆算する |
| USB-C ポートの位置 | ケースの開口位置 | 分割版では自分で決めてよい |
| 電池蓋の外寸と位置 | ケース底面 | 分割版では単3×2 に合わせて自分で設計する |
| ゴム足の位置 | ケース底面 | 自分で決めてよい |
| ベゼル 8.25mm の左右配分 | ケース外形 | 分割版では左右対称（各 4.1mm）とする |

**結論: 実機採寸は不要。** 打鍵面のジオメトリ（列ごとの高さ・角度・傾斜）と
ケース断面の骨格（手前 17.5mm / 奥 31.8mm / 傾斜 7.3°）はすべて確定しており、
残る項目は設計裁量か試作で詰める範囲に収まった。

## 6. 写真計測について

`tools/measure_photo.py` で実機写真（Wikimedia Commons、3829×1565px）を解析した。

**成果**: キーピッチを基準にした較正で、鍵盤面の幅を 286.11mm（理論値との差 0.36mm）と算出できた。較正手法そのものは妥当だと確認できた。

**限界**: 写真にわずかな回転と遠近が残っており、ケース外形の端点検出が破綻した（本体幅が鍵盤面より狭いという矛盾した値になった）。射影補正を入れれば解決するが、キー配置は §3 の2つの一次情報で確定しているため、**写真計測を精緻化する実益がないと判断して打ち切った。**
