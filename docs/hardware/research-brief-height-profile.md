# 調査依頼書: HHKB Professional HYBRID Type-S の高さ方向の形状

別環境の調査エージェントに渡すための自己完結したプロンプト。
以下をそのままコピーして使う。

---

## 依頼

**PFU「HHKB Professional HYBRID Type-S」（型番 PD-KB800 系）の、高さ方向の外形寸法を特定してください。**

私はこのキーボードの打鍵感を再現した分割型キーボードを自作しており、CAD でケースを設計するために断面形状の数値が必要です。平面（キー配置）は確定済みで、**高さ方向だけが未確定**です。

### 求める数値（優先度順）

| # | 項目 | 補足 |
|---|---|---|
| 1 | 各列のキートップ高さ（机上面から、mm） | 数字段・QWERTY段・ホーム段（ASDF）・ZXCV段・最下段の5つ。**最重要** |
| 2 | 各列のキートップの傾き角（度） | シリンドリカル・ステップスカルプチャの段付き角度 |
| 3 | 打鍵面の実効傾斜角（度） | ケース自体の傾斜。キートップを結んだ線の角度 |
| 4 | ケース手前縁の高さ（mm）と断面形状 | 手首が当たる部分。丸み・面取りの有無 |
| 5 | ケース奥縁の高さ（mm） | |
| 6 | チルトスタンド各段の角度（度）と支点位置 | 3段階あるとされる |

**数値が見つからない場合は、正射影に近い側面写真（真横から撮影されたもの）でも構いません。** 高解像度であるほどよく、スケール基準（定規・コイン・既知寸法の物体が同じ平面に写っている）があれば理想的です。写真から私が計測します。

## 前提として使ってよい確定事実

以下は PFU 公式仕様または複数の一次情報で確認済みです。**再調査は不要**です。

| 項目 | 値 | 出典 |
|---|---|---|
| 幅 | 294mm | PFU 公式仕様 |
| **奥行** | **120mm** | PFU 公式仕様（※後述の注意参照） |
| 高さ | **40mm（キートップ上面まで）** | PFU 公式仕様 |
| キーピッチ | 19.05mm | PFU 公式仕様 |
| キーストローク | 3.8mm | PFU 公式仕様 |
| 押下圧 | 45g | PFU 公式仕様 |
| 質量 | 540g（電池含まず） | PFU 公式仕様 |
| 電源 | 単3形乾電池×2本／USB 給電 | PFU 公式仕様 |
| キー配置 | US 配列 60 キー。全行 15u。最下段は `余白1.5u + 1u + 1.5u + 6u + 1.5u + 1u + 余白2.5u` | QMK `keyboards/hhkb/ansi/info.json` と Wikimedia Commons の KLE 図が一致 |

**未確定だが有力な候補値**（出典が品番不明のレビュー記事のため、裏取りできれば有用）:
フレーム上面までの高さが手前 20mm・奥 32mm、チルトスタンドが 0° / 3° / 6° の3段階。
公称の 40mm との差 8mm がキーキャップの突き出しとして妥当なので、大きくは外れていないと思われます。**この 2 値の裏を取れるだけでも大きな成果です。**

## 絶対に守ってほしい注意（過去に実害が出た落とし穴）

### 1. 品番差 — 特に奥行

HHKB には多くの派生があり、**キー部分以外に無視できない差**があります。

| モデル | 配列 | 奥行 | 電池 | 端子 |
|---|---|---|---|---|
| **HYBRID / HYBRID Type-S（PD-KB800/820 系）← 調査対象** | US 60 / JIS 69 | **120mm** | 単3×2 | USB-C |
| Professional BT（PD-KB600 系） | US 60 | 120mm | 単3×2 | micro USB |
| Professional 2（PD-KB400 系） | US 60 | **110mm** | **なし** | mini USB |
| Classic（PD-KB401 系） | US 60 | **110mm** | **なし** | USB-C |
| HHKB Lite 2 / 1st Generation | — | — | — | 筐体が別物 |
| HHKB Studio（PD-ID100） | — | — | — | 全く別の製品 |

**電池を積むモデルは奥行が 10mm 長い。** この差を見落として「奥行 108mm」という誤情報を採用し、設計をやり直した経緯があります。**資料を使う前に必ず品番を確定してください。**

ただし **キーキャップの列プロファイル（項目1・2）は Professional 系で共通**と見てよいので、Professional 2 や Classic の資料も使えます。**奥行方向の量（項目3・4・5・6）は電池搭載モデルのものだけ**を使ってください。

### 2. 被写体の同定 — 「公式記事だから HHKB」は成り立たない

PFU 公式サイトのキーキャップ解説記事（`happyhackingkb.com/jp/life/hhkb_life76.html`）は、
画像 30 枚のうち **HHKB は 5 枚だけ**で、残りは他社製キーボードの例示でした。
実際に「これが HHKB の側面写真だ」と誤認しかけた事故があります。

**同定の手掛かり:**

- **キーキャップの下に MX 軸のハウジングが見えたら HHKB ではない**（HHKB は静電容量無接点）
- HHKB はケース上面にベゼルの段差がある。平板なら別機種
- Fn 面の刻印に `vol dn` / `vol up` / `mute` / `eject` があれば HHKB
- キーに `あ` `か` などのかな表記があれば**日本語配列**。US 配列の根拠には使えない
- ケース側面のロゴ（`Professional HYBRID` / `Professional 2` / `Professional BT`）

### 3. 日本語配列を混同しない

`HHKB Pro JP` 系は **JIS 69 キー**で最下段の構成もキー数も違います。
Wikimedia Commons にある分解写真はすべて日本語配列モデルです。

## 既に試して失敗した経路（再訪不要）

| 経路 | 結果 |
|---|---|
| PFU 公式マニュアル PDF（`P3PC-6631-08XA.pdf`） | 安全上の注意 2 ページのみ。**寸法図なし** |
| PFU 公式・happyhackingkb.com の製品ページ画像 | 最大 900px で精度不足 |
| Wikimedia Commons の HHKB 関連画像 40 件を全走査 | **真横からの写真が 1 枚もない** |
| PFU 公式キーキャップ解説記事（画像 30 枚） | HHKB は 5 枚のみ、いずれも斜めからの近接カット |
| pdweb.jp のレビュー記事 | 背面・底面は得られたが側面は不可 |
| キーキャップのプロファイル仕様（PFU・互換品各社） | **数値は非公開**。「純正と同じ高さ」としか書かれない |
| HHKB 用パームレストの製品仕様 | 適合品は 13〜18mm 厚という間接情報のみ |
| GrabCAD / Thingiverse の 3D モデル | **実機の複製ではなく汎用 60% PCB 向け**。寸法は信用できない |
| **FCC 認証の届出書類** | PFU の付与コード `FPJ` 配下は 2 件のみ（HHKB Studio と別製品）。**PD-KB800 系の届出が存在しない**。Bluetooth モジュールの認証を流用しているため製品単位の届出義務がなく、外観写真も寸法図も公開されない |
| **意匠登録・特許（Google Patents）** | PFU 名義のキーボード意匠・特許なし（スキャナ関連のみ）。東プレ名義は**スイッチ機構の特許のみ**で筐体形状を含まない |
| 日本語の分解ブログ・自作ケース記事 | 分解手順の記事はあるが**実測値や図面の公開なし** |

### 検索語の教訓

「HHKB 寸法」「HHKB dimensions」系の語では**製品スペック表しか出ません**。
高さ方向の資料に近づけたのは **「hhkb スカルプチャー」** のように
*形状の特徴を説明する語*で検索したときでした。
寸法そのものではなく、**その形状を解説している記事**を狙うほうが当たります。

## まだ試していない有望な経路（ここを重点的に）

1. **YouTube のレビュー動画** — side profile を映すカットがほぼ必ずある。動画からフレームを抽出すれば真横に近い静止画が得られる。「HHKB レビュー」「HHKB review」「HHKB unboxing」。**最有力**
2. **中古販売・オークションの出品写真** — ヤフオク、メルカリ、イオシス、じゃんぱら等。出品者は状態を示すため**真横・真後ろから撮る習慣がある**。定規を添えている出品もある。**最有力**
3. **J-PlatPat（日本の特許情報プラットフォーム）の意匠検索** — Google Patents は日本の意匠のカバレッジが弱い。**J-PlatPat で「意匠」を PFU／富士通高見沢コンポーネント名義で直接検索**する。意匠登録には**六面図**（正面・背面・左右側面・平面・底面）が含まれるため、当たれば一発で解決する
4. **英語・中国語・韓国語圏のレビュー** — deskthority、geekhack、reddit（r/Topre、r/MechanicalKeyboards）は**実測値を投稿する文化がある**。「HHKB height mm」「HHKB profile measurement」「HHKB キーキャップ 高さ」の各言語版
5. **キーボード比較記事** — 複数機種を横に並べて側面から撮った比較写真。既知寸法の他機種が同じ写真に写っていればスケール較正ができる
6. **HHKB 用アクセサリメーカーの開発ブログ** — パームレスト、キーボードルーフ、ハードケースのメーカー（バード電子など）は適合のため実測しているはず。開発記録や設計資料の公開がないか
7. **3D スキャン / フォトグラメトリのデータ公開** — Sketchfab、Thingiverse で「HHKB scan」
8. **雑誌・書籍のレビュー記事** — 日経 Linux、Software Design 等。図版に寸法入りの図がある可能性
9. **HHKB 互換ケース・互換キーキャップの設計者（GitHub / 個人サイト）** — 互換品を作る以上は実測しているはず
10. **和田英一氏（HHKB の設計思想の提唱者）の記事・講演資料** — 設計時の寸法根拠が書かれている可能性

## 受け入れ基準

- **数値には必ず出典 URL を付けてください。** 出典のない数値は採用できません
- **推測と実測を明確に分けてください。** 「おそらく」「と思われる」で数値を出す場合はそう明記してください
- **その数値がどの品番のものか**を必ず併記してください（HYBRID Type-S / Professional 2 など）
- 複数の情報源で食い違う場合は、**丸めずに両方報告**してください
- 写真を見つけた場合は、**URL・解像度・撮影角度の評価（真横に近いか）・被写体の品番同定根拠**を添えてください
