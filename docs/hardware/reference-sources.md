# 参照資料と調査ログ

ベース機（HHKB Professional 系）の寸法を確定させるために調べた経路の記録。
**成功した経路だけでなく、失敗した経路も残す。** 同じ袋小路を再訪しないため。

再取得:

```bash
.venv/bin/python tools/fetch_references.py          # 全部取得（build/photos/ へ）
.venv/bin/python tools/fetch_references.py --list   # 出典と用途の一覧
```

参照画像は他者の著作物なのでリポジトリには含めない（`build/` は `.gitignore` 済み）。
スクリプトが URL と用途を保持しているので、いつでも同じ状態を再現できる。

## 0. 品番差の注意（最重要）

集めた資料には**複数の品番が混在している**。基本的な機構は共通だが、
キー部分以外に無視できない差がある。**資料を使う前に必ず品番を確認すること。**

| モデル | 配列 | 奥行 | 電池 | 端子 | 資料として使ってよい範囲 |
|---|---|---|---|---|---|
| **HYBRID Type-S（PD-KB800 系）** ＝ ベース機 | US 60 キー | **120mm** | 単3×2 | USB-C | すべて |
| HYBRID（PD-KB800 系・非 Type-S） | US 60 キー | 120mm | 単3×2 | USB-C | すべて（ストローク以外同一） |
| Professional BT（PD-KB600 系） | US 60 キー | 120mm | 単3×2 | micro USB | 電池室・背面配置は参考になる。端子は違う |
| Professional 2（PD-KB400 系） | US 60 キー | 110mm | **なし** | mini USB | **奥行と背面は使用不可**。キー配置と側面プロファイルのみ |
| Classic（PD-KB401 系） | US 60 キー | 110mm | **なし** | USB-C | 同上 |
| **HHKB Pro JP 系** | **JIS 69 キー** | — | — | — | **配列の根拠に使用禁止。下段構成もキー数も違う** |
| **HHKB Lite 2 / 1st Gen** | — | — | — | — | **筐体が別物。使用禁止** |

### 具体的な誤用リスク

- Commons の分解写真は `HHKB Pro JP Type-S` すなわち**日本語配列**。プレートと
  基板のキー配置は US と異なる。**ケース内部の構造把握には使えるが、配列の根拠には使えない。**
- 電池ボックスの有無で**奥行が 10mm 変わる**。Professional 2 の写真から奥行方向の
  寸法を取ると 10mm ずれる。
- 端子は mini USB → micro USB → USB-C と世代で変わる。背面の開口位置は品番ごとに違う。

### 品番差に無関係で共通と見てよいもの

- キーピッチ 19.05mm、幅 294mm、高さ 40mm（キートップ上面まで）
- US 配列 60 キーの配置（Professional 系で共通）
- シリンドリカル・ステップスカルプチャの列プロファイル
- チルトスタンドの機構

## 2. 高さ方向（機構）— **Web では取得できなかった**

**結論: PFU 公式解説記事に、HHKB の使える真横写真は存在しない。**

**PFU 公式解説記事**「キーキャップのプロファイルと種類・印字方法について解説」
<https://happyhackingkb.com/jp/life/hhkb_life76.html>（画像 30 枚）

この記事は**キーキャップ一般の解説**であり、**HHKB 以外のキーボードを例示に多用している**。
「PFU の記事だから被写体は HHKB」という思い込みが誤りだった。1 枚ずつ同定した結果:

| ファイル | 被写体 | 同定根拠 |
|---|---|---|
| `hhkb_life76-16` | **HHKB ではない** | ケースが平板でベゼル段差がない |
| `hhkb_life76-18` | **HHKB ではない** | キャップ下に **MX 軸のハウジングが露出**。HHKB は静電容量無接点 |
| `hhkb_life76-2` | **HHKB ではない** | 光沢キャップの別機種 |
| `hhkb_life76-30` | **HHKB ではない** | 自作機（軸サンプルが散らばった演出カット） |
| `hhkb_life76-9` | HHKB 白 US | `vol dn`/`vol up` 等の Fn 刻印。**斜めからの近接**で全体は写らない |
| `hhkb_life76-20` | HHKB 白 US | 同上 |
| `hhkb_life76-21` | HHKB 白 US | 同上 |
| `hhkb_life76-26` | HHKB **日本語配列** | `A ち`/`S と` の刻印。配列の根拠には使用禁止 |
| `hhkb_life76-1` | HHKB HYBRID 白 | ケースに `HHKB Professional HYBRID` の刻印 |
| `hhkb_life76-24` | 出典不明の線画 | キーキャップ断面図。**HHKB のものか一般論かは判別できない**。単独の根拠にしない |
| `hhkb_life76-15` | 各社キャップの比較 | Low / Standard(Cherry 相当) / Hi Profile の高さ比較。mm 値なし |

HHKB と確認できた 3 枚（`-9` / `-20` / `-21`）はいずれも**斜めからの近接カット**で、
全体の側面が正射影で写っていない。**列ごとの段差の傾向は読めるが、
mm 単位の採寸には使えない。**

### 教訓

**「PFU 公式の記事だから被写体も HHKB」は成り立たない。**
画像を採寸に使う前に、必ず被写体そのものを同定すること。
同定の手掛かり: 軸の露出有無（静電容量無接点なら MX ハウジングは見えない）、
ケースのベゼル段差、Fn 刻印の内容、ケース側面のロゴ。

**pdweb.jp レビュー記事**（HHKB Professional BT）
<http://www.pdweb.jp/column/c_md/c_md97.shtml>

| ファイル | 内容 |
|---|---|
| `97_03.jpg` | **背面（注釈付き）**。電池ボックス（単三×2）・電源スイッチ・USB 端子の位置 |
| `97_07.jpg` | 底面。チルト脚の機構 |
| `97_05.jpg` / `97_11.jpg` | 側面・斜め（注釈付き） |

背面写真から、**ベース機も単三×2 を奥側に横向きで搭載している**ことが確認できた。
乾電池を奥に置くという当プロジェクトの設計判断は実機と同じ構成になる。

### 高さ方向を確定させる唯一の残った手段

Web の探索は尽きた。**実機を真横から撮影するしかない。** 測定は不要で、撮るだけでよい。

1. 左側面から真横（チルトスタンドをしまった状態）
2. 左側面から真横（チルトスタンドを最大に立てた状態）
3. 右側面から真横（歪みの検証用）
4. 真後ろから

1 円玉（直径 20.0mm・厚さ 1.5mm、法定で厳密）をキーボード手前の同一平面上に置くと、
独立したスケール較正ができる。カメラはキーボードと同じ高さに置き、離れてズームで撮る。

### スケール基準（3 系統を相互に検算する）

1. **キーピッチ 19.05mm** — 真横写真では隣接キーキャップの中心間隔がこれにあたる
2. **キーキャップ基部の幅 約 18.2mm** — 断面線画の基準
3. **公称 294(W) × 120(D) × 40(H)mm（H はキートップ上面まで）** — 全体の整合性チェック。
   とくに **40mm** は独立した検算になる（採寸した最高列のキートップ高さが 40mm になるか）

実機撮影が 4 枚あれば、同じ量を複数回独立に測って平均と標準偏差を出せる。
**1 枚だけを信じる状態にはしない。**

### 採寸前に必ず済ませること — 各画像の被写体同定

**実施済み。結果は §2 の表を参照。** PFU の解説記事は HHKB 以外のキーボードを
多用しており、4 枚が HHKB ではなかった。**採寸に使う前に 1 枚ずつ同定する。** 手掛かり:

- 軸ハウジングの露出（静電容量無接点なら見えない。見えたら HHKB ではない）
- ケースのベゼル段差の有無

- ケース側面のロゴ表記（`Professional HYBRID` / `Professional 2` / `Professional BT`）
- 背面端子の形状（mini USB / micro USB / USB-C）
- 電池ボックスの有無

奥行方向の量（傾斜角、前後の高さ）は**電池の有無で 10mm 変わる**ため、
品番を確定させずに測ってはいけない。一方、**列ごとのキートップ段差と傾き角は
キーキャップの形状で決まる**ので、Professional 系であれば品番差の影響を受けない。

## 3. 失敗した経路（再訪しないこと）

| 経路 | 結果 |
|---|---|
| PFU 公式マニュアル PDF `P3PC-6631-08XA.pdf` | **安全上の注意 2 ページのみ。寸法図なし** |
| PFU / happyhackingkb.com の製品ページ画像 | 最大 900px。1px ≈ 0.35mm で精度不足 |
| Wikimedia Commons の全 HHKB 画像（40 件走査） | **真横からの写真は 1 枚もない**。俯瞰・斜め・分解のみ |
| PFU 公式のキーキャップ解説記事（画像 30 枚） | HHKB は 5 枚のみで、いずれも斜めからの近接カット。**採寸可能な真横写真はない**。4 枚は HHKB ですらなかった |
| キーキャップのプロファイル仕様（各社） | PFU も互換品メーカーも**数値は非公開**。「純正と同じ高さ」としか書かない |
| パームレスト製品の仕様 | 適合品は 13〜18mm 厚。公称の手前 20mm と整合するが、キートップ高さは得られない |
| GrabCAD / Thingiverse の 3D モデル | **実機の複製ではなく汎用 60% PCB 向け**。寸法は信用できない |
| QMK `layouts/community/60_hhkb/` | 存在しない（404） |

### 検索語の教訓

「HHKB 寸法」「dimensions」系の語では**製品スペック表しか出ない**。
高さ方向の資料に辿り着いたのは **「hhkb スカルプチャー」** という
*形状の特徴を表す語*で検索したときだった。寸法そのものではなく、
**その寸法を説明している記事**を狙うほうが当たる。

## 4. 著作権の扱い

- 参照画像はすべて他者の著作物。**私的な採寸参照としてのみ使用し、再配布しない。**
- リポジトリには URL と用途のみを記録し、画像実体は含めない（`build/` は git 管理外）。
- Wikimedia Commons の画像は個々のライセンス表記に従う。採寸結果を公開する場合は
  出典表記を付ける。
- 採寸から得られる**寸法の数値そのものは事実であり著作物ではない**ため、
  [dimensions.md](dimensions.md) に記録して差し支えない。
