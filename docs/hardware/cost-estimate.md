## 2. 見積もりに留まる額（**発注ページで確認が要る**）

JLCPCB の見積もり API は見つけられなかった。以下は公開されている料率から
計算した**概算**で、確定値ではない。

### 基板そのもの

## 4. 減らせるところ（効果の大きい順）

### 4-1. 実装するのは 2 セットでよい（**約 ¥2,700**）

キーボードは左右 1 枚ずつ＋子基板 2 枚で成立する。**5 セット実装しても
使い道が無い。**2 セットなら 1 台分の予備が残る。板は 5 枚来る（最低数量）
ので、残りは未実装のまま予備になる。

### 4-2. 子基板を自分で半田付けする（**約 ¥1,200**）

子基板に載るのは**パスコン 1 個と FFC コネクタ 1 個だけ**。この 1 種類の
ために実装の基本料 $8 を払うことになる。**ただし FFC は 0.5mm ピッチ**なので、
手半田は容易ではない。腕と相談。

### 4-3. 74HC595 を SOIC-16 にする（**約 ¥450**・見送り中）

C5947（SOIC-16）は Basic で段取り費 $0。TSSOP-16（C5948）は
`preferredComponentFlag` も false で正真正銘の Extended。
SOIC-16 は 90 度回せば帯に入る（7.40mm・余裕 +0.92mm。実測済み）が、
幅が 6.4→10.4mm になって隣と 0.4mm 重なり、配線し直すと右基板に違反が
9 件出た。**DRC 0 の基板を崩す価値は無い**と判断して見送った。

## 5. 注意

**FFC コネクタの在庫が 2,868 個しかない。**必要 15 個なので足りるが、
この案件で最も薄い。`FH12-12S-0.5SH(54)` は製造中止（後継 FH52K）で、
在庫があるのは (55)。**無くなればフットプリントごと変えることになる。**

**この見積もりは 3 回外したあとのもの。**最初「FFC は ¥4,000」と書き、
次に「¥1,100」と書き、実際は ¥600 だった。数量 1 の価格を掛けていたため。
**発注ページの実額と必ず突き合わせること。**
