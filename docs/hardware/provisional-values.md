## ⚠️ `AA_TERMINAL` は「電池ボックス」の寸法ではない（2026-08-08 に取り違えた）

**この表は以前「電池ボックスが届いたら測る」と書いていた。**
`AA_TERMINAL` の定義は「**電極バネ**と配線に要る余裕」なのに、測る対象が
「箱」になっていた。**定義と測定対象が食い違っていた。**

その結果、買い物リストに「電池ボックス 単3×2」と書いてしまい、
**設計に入らない横並び型（58 × 32mm）を買う**ことになった。
コブの内寸は 15.6mm しかない。

### いまの設計は「箱を使わない」

`envelopes.battery_envelope` と `gen_case` は、**裸の単3 を 2 本、
一直線に寝かせて**ケース自身で保持する形。

```
電池は 手前=仕切り壁 / 左右と奥=側壁 / 下=蓋 / 上=コブの天井 で保持される
（**基板ではない。**基板の後端 y=+48.7 に対し、電池は y +52.1〜+67.6 で 3.4mm 後ろ。
 「上=基板」と書いていたのは誤り。2026-08-08 に訂正）
```

占有は **109 × 15.5 × 15.5mm**。必要な部品は**電極バネとリード線**だけで、
プラスチックの箱は買わない。

### 電池ボックスを使うなら

**箱の厚みぶん電池室を広げる必要がある。**一直線型（110 × 17 × 17mm 級）
なら +1〜2.5mm。**横並び型（58 × 32mm）は入らない**（コブを 17mm
深くすることになり、ケース奥行が 125 → 142mm。実機 120mm から +22mm）。

**どちらにするかは未決定**（open-gaps #22）。買う前に、実物の外形寸法を
`envelopes.py` に入れて `gen_assembly.py` を通すこと。

## 確定させたときの手順

1. 実測値を `tools/envelopes.py` に入れ、タグを `[暫定]` → `[確定]` に変える
2. **この表から行を消す**（消し忘れると `test_the_provisional_list_has_no_stale_entries`
   が落ちる）
3. 根拠（測り方と測定値）を [dimensions.md](dimensions.md) に書く
4. `pytest tools` と `python3 tools/gen_assembly.py` を通す
