# まだ実測していない値

**推定で埋めた値と、確かめた値が区別できないと、どこがまだ危ないのかが
分からなくなる。** この案件では、タクトスイッチの向きも XIAO のピンピッチも
推定のまま断定し、どちらも利用者に指摘されて初めて誤りだと分かった。

ここは `[暫定]` と書かれた定数の一覧。
[tools/test_constants.py](../../tools/test_constants.py) が
**コードとこの表がずれたら落ちる**ようにしてある。書き漏らしも、
実測して確定したのに残っている行も、どちらも検出される。

## 確定させる順番

1. **`XIAO_L/W/H` と `DB_STACK_H`** — 手元に XIAO があるので今日測れる。
   子基板の設計とケースの USB 切り欠きが、これで固まる
2. **`AA_TERMINAL`** — 電池ボックス到着後（明日見込み）
3. **`SOCKET_DROP`** — ソケット到着後
4. **`PLATE_TO_PCB`** — MX スイッチとキーキャップ到着後。
   ここが決まると `PLATE_TOP_FRONT` を動かしてホーム段 31.6mm に合わせられる

---

## 確定させたときの手順

1. 実測値を `tools/envelopes.py` に入れ、タグを `[暫定]` → `[確定]` に変える
2. **この表から行を消す**（消し忘れると `test_the_provisional_list_has_no_stale_entries`
   が落ちる）
3. 根拠（測り方と測定値）を [dimensions.md](dimensions.md) に書く
4. `pytest tools` と `python3 tools/gen_assembly.py` を通す
