# Task C6 — 実機で確かめる（DIP スイッチとキーマップ）

**部品の到着を待たずにできる。** そして**私にはできない確認**でもある。

所要 15 分ほど。

---

## 1. なぜやるか

キーマップは Wikimedia Commons の刻印つき KLE 図と実機写真の前面刻印から
読み取った（[dimensions.md](dimensions.md) §4）。**推測で埋めた箇所は無い。**

ただし次の 2 つは、資料からは決められない。

| 確認したいこと | 資料で決められない理由 |
|---|---|
| **DIP スイッチの現在の設定** | 個体ごとに違う。あなたがどう使っているかは実機にしかない |
| **Keymap Tool で変更していないか** | 同上 |

**ここが違うと、完成したキーボードが「今の HHKB と違う」ものになる。**
配列を再現するのが唯一の目的なので、外せない確認。

## 2. DIP スイッチを見る

キーボードを裏返し、**裏面のカバーを開ける**（電池蓋とは別）。
6 個のスイッチが並んでいる。**現在の位置をそのまま記録してほしい。**

| SW | 機能（HHKB Professional HYBRID Type-S） | 現在 |
|---|---|---|
| **SW1** | Mac / PC モード（SW2 と組で使う） | ON / OFF |
| **SW2** | 同上 | ON / OFF |
| **SW3** | **Delete → Backspace に変える** | ON / OFF |
| **SW4** | **左◇ と 左Alt を入れ替える** | ON / OFF |
| **SW5** | Alt / ◇ を無効化 | ON / OFF |
| **SW6** | Fn とControl を入れ替える等 | ON / OFF |

**SW3 と SW4 が最重要。**

- **SW3**（Delete → Backspace）: 右上の大きいキーが Delete なのか
  Backspace なのかが変わる。現在のキーマップは **Delete** で作ってある
- **SW4**（左◇ と 左Alt の入替）: 最下段のどちらが ◇ でどちらが Alt かが
  変わる。物理的な幅の並び（外側 1u / スペース寄り 1.5u）は不変

写真を撮って貼っていただければ、こちらで読み取ります。

### 動作で確かめる方法（カバーを開けたくない場合）

| 試すこと | 結果でわかること |
|---|---|
| 右上の大きいキーを押す | **文字が消える方向**が右なら Delete、左なら Backspace（SW3） |
| 左下から 2 番目（1.5u のキー）を押しながら C | **コピーできれば ◇**（Mac）。何も起きなければ Alt（SW4） |

## 3. Keymap Tool の設定を見る

PFU の Keymap Tool（Web アプリ）で現在の設定を書き出す。

1. Keymap Tool を開いて HHKB を接続する
2. 現在の設定を読み込む
3. **書き出し（エクスポート）してファイルを送る**

標準から一切変えていないなら「変えていない」と一言で十分です。

## 4. Fn 面で確信が持てない箇所

資料から読み取ったが、**実機で押して確かめたい**箇所が 4 つある。

現在のキーマップでは**テンキーの演算子**として実装してある
（`config/boards/shields/hhkb_split/hhkb_split.keymap` の 99〜100 行目）。

| 押す | 現在の実装 | 実機では何が出るか |
|---|---|---|
| `Fn + H` | `*`（テンキーの乗算） | |
| `Fn + J` | `/`（テンキーの除算） | |
| `Fn + N` | `+`（テンキーの加算） | |
| `Fn + M` | `-`（テンキーの減算） | |

**テキストエディタで押して、出た文字をそのまま教えてほしい。**

見た目は同じ記号でも、テンキーの `*` と通常の `Shift+8` の `*` は
キーコードが違う。アプリによって挙動が変わる（表計算ソフトなど）ので、
どちらなのかを合わせておきたい。

### ついでに確かめたい箇所

| 押す | 現在の実装 | 実機 |
|---|---|---|
| `Fn + Tab` | Caps Lock | |
| `Fn + \` | Insert | |
| `` Fn + ` `` | Delete | |
| `Fn + [` `;` `'` `/` | ↑ ← → ↓ | |
| `Fn + Esc` | 電源キー | |
