# HHKB 互換 完全分割型キーボード 設計仕様書

- 作成日: 2026-08-04
- ベース機: PFU HHKB Professional HYBRID Type-S 雪 英語配列 無刻印 (PD-KB800WNS)
- 目的: ベース機の使い勝手を可能な限り維持したまま、左右完全分割型として自作する

---

## 1. 設計原則

1. **HHKB の使い勝手を再現することが唯一の目的**。分割によって得られる肩幅・手首角度以外の「改善」は狙わない。
2. **HHKB に無い機能は入れない**。キーマップ・機構ともにベース機の挙動をそのまま移植する。
3. **打鍵感（静電容量無接点）の再現は放棄する**。メカニカル軸で代替し、ホットスワップで後から追い込む。
4. **手戻りの大きい判断ほど前倒しで検証する**。基板発注前にブレッドボードで方式を確定させる。

### 優先度

| 優先度 | 項目 |
|---|---|
| 必須 | キー配列（HHKB 配列そのもの） |
| 必須 | サイズ感・キー数（60% ロースタッガード、独立矢印なし） |
| 必須 | 接続性（Bluetooth 複数台切替 ＋ USB-C 有線） |
| 必須 | **左右間も無線であること**（完全ワイヤレス分割。左右を結ぶケーブルを常用構成に含めない） |
| 必須 | 日本国内で合法に電波を出せること（技適取得済みモジュール使用） |
| 妥協可 | 打鍵感（静電容量無接点 → メカニカル） |

## 2. 物理配列

総キー数 **61**（HHKB 60 キー ＋ 分割により増えるスペース 1 つ）。

```
【左 27キー・幅7.25u】                    【右 34キー・幅9u】

Esc  1   2   3   4   5                    6   7   8   9   0   -   =   \   `
[Tab 1.5u] Q  W  E  R  T                    Y   U   I   O   P   [   ]  [Del 1.5u]
[Ctrl 1.75u]  A  S  D  F  G                   H   J   K   L   ;   '  [Enter 2.25u]
[Shift 2.25u]   Z  X  C  V  B                   N   M   ,   .   /  [Shift 1.75u] Fn
 [◇1.5u][Alt 1u][ L-Space 3u ]              [ R-Space 3u ][Alt 1u][◇1.5u]
```

### 分割方針

- タッチタイピングの担当どおりに縦割りする。重複キーは置かない。
- ロースタッガード（行ずれ）は HHKB と完全同一。右半分は各行が 0 / 0.5u / 0.75u / 1.25u だけ内側に入り込む。
- HHKB の 6u スペースバーを 3u + 3u に分割し、**左右とも Space として使う**。追加キーは一切設けない。

### キーサイズ

1u = 19.05mm。HHKB の特殊サイズをすべて維持する。

| キー | サイズ |
|---|---|
| Tab / 左◇ / 右◇ / Delete | 1.5u |
| Ctrl（CapsLock 位置） / 右Shift | 1.75u |
| Enter / 左Shift | 2.25u |
| L-Space / R-Space | 3u |
| その他 | 1u |

### 分割による指使いへの影響

影響なし。以下を確認済み。

- 矢印（Fn + `[` `;` `'` `/`）は Fn も矢印も右半分にあるため、HHKB と同じく右手だけで完結する。
- F1〜F12（Fn + 数字段）は Fn が右手・数字段が左手で、HHKB と同じく両手を使う。
- 分割によって片手・両手の別が変わる組み合わせは存在しない。

### キーキャップ

- 無刻印 PBT、Cherry MX 軸対応、**Cherry プロファイル**（HHKB のシリンドリカル・ステップスカルプチャ構造に最も近い）。
- **調達上の唯一の難所**: 3u スペースバー × 2。60% 標準セットには含まれないため、分割キーボード向け／ergo 系のセットから調達する。入手できない場合は 2.75u × 2 に変更する。

## 3. キーマップ

### レイヤー構成

| レイヤー | 役割 | 入り方 |
|---|---|---|
| 0: Base | HHKB ベース配列。L/R Space はどちらも Space | 起動時の既定 |
| 1: Fn | HHKB の Fn 面をそのまま移植 | Fn 押下中のみ（momentary） |
| 2: Fn+Ctrl | BT 切替と OS モード切替 | Fn と Ctrl の同時押しで自動的に有効化（conditional layer） |
| 3: Mac / 4: Win | OS 別の既定レイヤー | `Fn+Ctrl+M` / `Fn+Ctrl+W` |

### Fn レイヤー（判明済みの割り当て）

- `Fn + 1`〜`0` / `-` / `=` → F1〜F12
- `Fn + \` → Insert、`` Fn + ` `` → Delete
- `Fn + Tab` → Caps Lock
- `Fn + [` `;` `'` `/` → ↑ ← → ↓

**未確定**: Home / End / PageUp / PageDown、音量・メディアキー等の残りの割り当て。無刻印のため実機の刻印からは読み取れない。→ **PD-KB800WNS の Keymap Tool から現行設定を書き出し、それを正として移植する**（推測で埋めない）。

### Bluetooth / OS モード切替

ベース機と同一の操作で再現する。

| 操作 | 動作 |
|---|---|
| `Fn + Ctrl + 1`〜`4` | Bluetooth プロファイル 1〜4 へ切替 |
| `Fn + Ctrl + 0` | USB 接続へ切替 |
| `Fn + Ctrl + M` | Mac モードへ切替 |
| `Fn + Ctrl + W` | Windows モードへ切替 |

ZMK は BLE プロファイルを 5 つ保持できるため 4 台切替を収容できる。また ZMK の既定レイヤーは再起動でリセットされるため、**「電源を切ると DIP スイッチの設定に戻る」というベース機の仕様が追加実装なしで一致する**。

### DIP スイッチの扱い

物理 DIP は実装しない。ベース機で現在使用している SW1〜SW6 の設定をキーマップに焼き込む。Mac / Windows 切替のみ上記ショートカットでソフト的に行う。

**未確定**: ベース機の現行 DIP 設定（SW1〜SW6）。キーボード裏面カバー内で確認して反映する。特に SW3（Delete → Backspace）、SW4（左◇と左 Alt の入替）は使い勝手に直結する。

### 実装しないもの（明示的除外）

RGB、OLED、ロータリーエンコーダ、タップダンス、ホールドタップ、コンボ、マクロ、HHKB に存在しない独自レイヤー。

## 4. ハードウェア

### 制御系

| 項目 | 選定 | 理由・備考 |
|---|---|---|
| MCU | Seeed XIAO nRF52840 × 2 | **技適取得済み**。ZMK 公式ボード対応。ピンソケット実装で交換可能にする |
| ファームウェア | ZMK | 分割 BLE の本流。長期サポートが見込める |
| キースキャン | チャープレックス配線 | 左 6 ピン（30 キー分／27 使用）、右 7 ピン（42 キー分／34 使用） |
| ダイオード | 1N4148W (SMD) × 61 | JLCPCB Basic Parts、PCBA 委託 |
| ソケット | Kailh MX ホットスワップソケット × 61 | 手はんだ |
| スイッチ | 静音リニア 45g 前後 × 61（初回） | Type-S の静粛性と軽さを狙う。後から自由に交換可能 |
| プレート | FR4 1.6mm | PCB と同時に JLCPCB へ発注 |
| 左右連結（切り分け用） | TRRS ジャック × 2 | **フットプリントのみ設計、部品は実装しない**。左右間の無線は必須要件であり、有線化は常用構成として想定しない。BLE 側の不具合切り分けや、無線が原理的に成立しないと判明した場合の最終手段としてのみ残す |

GPIO 配分（XIAO は 11 本）:

| | キースキャン | TRRS(UART) | 電池電圧測定 | 予備 |
|---|---|---|---|---|
| 左 | 6 | 2 | 1 | 2 |
| 右 | 7 | 2 | 1 | 1 |

### 電源

**乾電池方式**（ベース機と同じ思想）。単3 × 2 本を左右それぞれに搭載（合計 4 本）。

- アルカリ単3 2 本（約 2000mAh）で **3〜8ヶ月**の見込み。ベース機（公称 3ヶ月程度）と同等以上。
- 電圧: アルカリ新品 3.2V 〜 終止 2.0V、エネループ 2.4V。いずれも nRF52840 の動作範囲（1.7〜3.6V）内。
- リポの発火リスク・経年劣化・充電管理が不要になる。

**回路上の注意（重要）**

XIAO nRF52840 の BAT 端子はリポ用充電回路に直結しているため、**乾電池を BAT 端子に接続してはならない**（USB 接続時に一次電池を充電しようとして液漏れ・破裂の危険がある）。代わりに次の経路とする。

```
単3 × 2 → スライドスイッチ → ショットキーダイオード → XIAO の 3V3 ピン
                                    ↑
                    USB 接続を検出したら P-MOSFET で電池側を自動切離し
```

- 部品点数は 5 点程度、すべて PCBA で委託可能。
- 挙動はベース機と同じく「USB を挿せば有線＆電池を消費しない、抜けば無線」となる。
- 電池残量表示は XIAO 内蔵の測定回路（BAT 端子側）が使えないため、空き GPIO へ分圧抵抗を自前で引き、ZMK の任意電圧センサとして設定する。

**検証必須項目**: 3V3 ピンへの外部給電時に基板上のレギュレータへ電流が逆流しないこと。逆流する場合はレギュレータを除去する（一般的な改造）か、MCU を基板直付けに変更する。

### その他の部品

- スライドスイッチ（電源）× 2
- タクトスイッチ（リセット／ファーム書込み用）× 2、ケース底面配置
- M2 ネジ・スペーサー、ゴム足
- 1/4 インチナット（三脚ネジ穴）× 左右各 1、底面埋込み

## 5. ケース

### 構成

```
無刻印キーキャップ（Cherry プロファイル）
FR4 スイッチプレート 1.6mm    ← JLCPCB で PCB と同時発注
PCB（ソケット・ダイオードは裏面）
3Dプリント ボトムケース        ← 単3電池 × 2、スイッチ類を内蔵
ゴム足 4点 × 2
```

- 製法: JLC3DP の MJF ナイロン（PA12）を想定。積層痕がほぼ無く割れにくい。左右で ¥3,000〜6,000 程度。
- M2 ネジ＋スペーサーで締結。

### 再現する機構

| ベース機の機構 | 自作版での再現方法 |
|---|---|
| 本体の傾斜（奥が高く手前が低い断面） | 実寸に合わせてボトムケースを造形。奥に単3電池を寝かせるため厚みも自然に一致する |
| チルトスタンド 3 段階（0° / 3° / 6°） | まず 0° 相当の固定角度で作る。他の角度を使う場合はボトムだけ刷り直して差し替える |
| 電池蓋（スライド式） | 同じくスライド蓋を造形。開閉の所作をベース機に合わせる |
| ゴム足 | 実機と同じ位置・厚みの市販品 |
| USB-C ポート | 実機と同じ背面位置。左（中央側）が常用、右はファーム書込み・保守用 |
| テンティング | ベース機には無いが、底面に三脚ネジ穴のみ用意する（普段は使わない） |

### 寸法（公開情報から取得済み）

| 項目 | 値 | 出典 |
|---|---|---|
| 幅 | 294mm | PFU 公称 |
| 奥行 | 108mm | PFU 公称 |
| 高さ（手前・フレームまで） | 20mm | PFU 公称 |
| 高さ（奥・フレームまで） | 32mm | PFU 公称 |
| 本体固有の傾斜 | 約 6.3°（108mm で 12mm の高低差より算出） | 上記より計算 |
| チルトスタンド | 0° / 3° / 6° の 3 段階（本体傾斜への追加分） | 各種レビュー記事 |
| キーピッチ | 19.05mm（1u） | 標準 |

分割後は 1 枚あたり幅 294mm の約半分。左半分の実装幅は 7.25u ≒ 138mm、右半分は 9u ≒ 172mm（枠を除く）。

### 未確定（実機採寸が必要な項目）

公開情報からは取得できず、実機の採寸が必要なもの。**PCB 設計は先行できるため、採寸は後追いで構わない**。

1. USB-C ポートの位置（本体左端からの距離）
2. 電池蓋の外寸と位置
3. キーキャップ天面の高さ（最前列＝スペースバー列、最奥列＝数字段の 2 点）
4. 下段の水平位置（本体左端から ◇ 左端まで、スペースバー左端・右端）
   - HHKB 配列は keyboard-layout-editor 等の公開データからも取得可能だが、実機で検証することが望ましい
5. ゴム足の位置と厚み

### 参考資料

Thingiverse 等に HHKB 風 60% ケース／プレートの STL が複数公開されている。ただし実機の複製ではなく汎用 60% PCB 向けのため、寸法はそのまま信用せず参照にとどめる。

## 6. 製作の順序と検証計画

初挑戦の要素（分割・無線・チャープレックス・乾電池給電）が重なるため、**手戻りの大きい順に前倒しで潰す**。

| 段階 | 内容 | ここで確定させること |
|---|---|---|
| 1. 電気検証 | ブレッドボードで XIAO ＋ タクトスイッチ数個。7 ピン・チャープレックスが ZMK で動作するか、乾電池からの 3V3 給電で逆流が無いかを実測 | 基板発注前に方式そのものの可否 |
| 2. 無線検証 | XIAO 2 個で ZMK 分割を構成。左右同時押し、BLE 4 台切替を確認。遅延が気になる場合は BLE 接続間隔（`CONFIG_BT_PERIPHERAL_PREF_MIN_INT` 等）を詰めて追い込む | 無線分割を実用水準に仕上げる。有線化は選択肢に含めない |
| 3. キーマップ | Keymap Tool の書き出しを ZMK へ移植し、段階 1 の環境で打ち比べ | Fn レイヤーの取りこぼし |
| 4. PCB 設計 | KiCad で左右 2 種。TRRS はフットプリントのみ | — |
| 5. 発注 | JLCPCB へ PCB ＋ PCBA。FR4 プレートも同時発注 | — |
| 6. 組立・実戦投入 | ソケットはんだ付け、仮ケース（平板）で使い込む | 配列そのものの違和感 |
| 7. ケース | 実機採寸をもとに 3Dプリント。刷り直して詰める | — |

段階 1・2 は XIAO 2 個（約 ¥3,600）だけで開始できる。方式を確定してから基板を発注することで、数万円規模の手戻りを防ぐ。

### 既知のリスク

| リスク | 影響 | 対策 |
|---|---|---|
| チャープレックス配線の採用例が少なく、不具合時の情報が乏しい | 設計やり直し | 段階 1 で検証。不可なら duplex マトリクス（ダイオード 2 個/キー）へ切替 |
| 無線分割では周辺側（右）に数ミリ秒の遅延が乗り、左右をほぼ同時に叩くとまれに押下順が入れ替わる | 打鍵の取りこぼし感 | 左右間無線は必須要件のため有線化では逃げない。段階 2 で体感確認し、BLE 接続間隔を最短（7.5ms）付近に設定して詰める。ZMK の分割は修飾キーを先に押して保持する通常のタイピングでは順序が崩れないため、実用上の影響は小さいと見込む |
| 3V3 ピンへの外部給電でレギュレータへ逆流する可能性 | 電池の異常消耗 | 段階 1 で電流実測。レギュレータ除去または MCU 直付けへ変更 |
| 3u スペースバーの無刻印キーキャップが入手困難 | 見た目・打鍵位置 | 2.75u × 2 へ変更（PCB 設計時に両対応のフットプリントを検討） |
